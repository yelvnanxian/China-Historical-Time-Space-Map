# 山河纪 · 中国历史时空地图

V0.6.0 提供城池／山川河流／同时显示三种模式，可点选山系范围、河道和湖面。地图设置统一收进可关闭的工具面板，已移除安史之乱专题入口，并修复宋代“00”占位名称。React + TypeScript + MapLibre GL JS，Express 只读 API，本地 JSON/GeoJSON 与高程瓦片。按用户需求用于个人本机浏览。

## 启动

需要 Node.js 22.12+。

```sh
npm install
npm run dev
```

开发页面 http://127.0.0.1:5173 ，API 使用 3001 端口。

```sh
npm test
npm run build
npm start
```

构建后访问 http://127.0.0.1:3001 。先停止开发服务器，避免占用同一端口。

## 看边界与查行政区

- 在朝代选择器中选择唐、宋、元、明、清，地图加载该朝代已有资料；“行政边界”卡片单独标明资料年份，年份与页面截面不同会提示。
- 点地图右下工具按钮，展开“行政边界”后开启或关闭省道、府州、县及部分独立政权/诸部层级。线宽、颜色、区域标签随层级与缩放区分；县界从较大缩放级别显示。可关闭整个工具面板，设置继续生效。
- 点选区域查看简体名称、原文名称、现代参考地区、年份和来源；也可在“查找当前资料中的行政区”输入“蓝田”“西安市”等古名或今名并定位。开启古今对照后，地图区域标签同时显示简体古名与今地参考。
- 地图左下方“历史地图原图”提供18张完整扫描图，覆盖11个时期；可选择图幅、放大、拖动、适配全图和按Esc退出，保留国家/政权范围及原图图例。
- 普通地点档案仍为40个，唐代37个，默认全部显示；同一地点可同时显示古名与现代对应地区。“观山河”播放功能保持取消。

## V0.6 交互与地图空间

- 顶栏可切换“城池”“山川河流”“同时显示”；山川模式隐藏城池和行政界，城池模式隐藏自然范围、河湖、山影与立体地形。切回自然模式恢复地形偏好。
- 52个山系、10个高原、8个海域显示来源中的概括多边形；277段河线和234个湖面可点击高亮。共581条图形记录、540个检索分组，并非581个独立自然地物。
- 点范围或名称可查看详情、完整范围和来源；黄河、长江的多个已收录河段联动高亮。在地图工具中可搜索“秦岭”“黄河”“青海湖”等，并按自然地理类型筛选。
- 默认不再覆盖年份大卡片、固定地形面板、固定行政边界面板。地点档案移到顶栏，图层与地形并入工具面板；工具可点关闭或Esc收起，自然详情也可折叠或关闭。
- 安史之乱专题已从发布目录与界面移除；旧专题链接归入普通地图，原有历史事件仍作为本期事件可检索。
- 宋金1200年资料中的“00”是源名称占位值。依据同源编码及10个下级府州的名称、几何一致性恢复显示为“山东西路”；原始资料保留，详情附核查依据，不把该条错位字段当作归属。

山系面属于Natural Earth 1:1000万地图命名概括范围，不是测绘或精确山体分界。河流高亮是现代线位，不表示河宽、流域或古河道。源中没有横断山、长白山的命名范围，本版没有补画替代面。详见[交互范围来源](docs/自然地理交互范围与来源.md)、[占位名修复](docs/历史区域占位名称修复.md)、[V0.6验收](docs/V0.6验收记录.md)。

## V0.5 新功能

- **历史地理**：地图底栏入口提供8条跨时期条目，涵盖1128、1855年黄河改道、1938年花园口决堤与1947年堵口，以及邗沟、都江堰、隋代运河。可查看影响、原文和出处并定位地区参考点；未复原古河道几何线。
- **古今名称与简体字**：现有25层12,111条历史区域都有简体显示，8,056条名称发生字形转换。12,100条有代表点所在现代地区参考，11条近海/岛礁记录明确未匹配。来源为GADM 4.1（2022版）、geoBoundaries（2019资料）与Natural Earth；不承诺2026实时区划，也不把代表点对应认作整片古辖区或同一城市实体。
- **山川起伏**：默认真实山影，可切换平面/立体、近览横断山脉。使用454张本地Mapzen / Tilezen高程瓦片，约34.30MB，覆盖55°E–155°E、5°S–65°N。原始z0–6，适合区域观察；立体高度夸张1.5倍，地形失败会独立降级。
- **历代大事记**：长安、洛阳、开封、南京、北京、杭州、成都、江陵、广州、扬州共35个节点，在地点档案中跨时期展示。新增内容共22个来源、52条原文摘录；百科概述与古籍原文区分说明，不标成全面史料考证。

详见[古今对照](docs/古今地名对照与简体字.md)、[历史地理与大事记](docs/历史地理与城市大事记.md)、[高程来源](data/evidence/terrain/README.md)、[V0.5验收记录](docs/V0.5验收记录.md)。

## 已接入的资料

| 数据集 | 资料年份 | 规模与范围 |
|---|---|---|
| Hartwell / CHGIS V5 | 741、1080、1200、1290、1391 | 20层、9,365个面，包含道省、府州、县及部分独立政权/诸部 |
| CHGIS V6 | 1820 | 32个省级/大区域、320个府级区域；本次未取得县面 |
| CHGIS V6 | 1911 | 27个省级/大区域、381个府级、1,986个县级区域 |
| 《中国历史地图集》纸图影像 | 各图独立年代 | 18张完整扫描图，11个时期，约28MB |

合计7个GIS资料年份、25层、12,111个区域面。数量是各年份、各层级的记录总数，包含重复时期及上下级重叠，不是12,111个独立城市。没有用点连线、平滑手绘轮廓或拼合现代行政区来冒充本项目考据出的国界。

Hartwell来源本身是以现代县界构造的近似历史行政模型，不能称为已逐段核实的历史疆界；741/742、1290/1280等来源年份存在不一致，采用实际文件年份并保留说明。CHGIS部分原始年份字段冲突、拓扑修复和基准转换精度均有记录。行政区面不等于古城城墙，也不自动等于完整国界；完整政权图通过原图阅读器提供，不将未配准的纸图强行套到交互底图。

原始资料、来源ID、下载校验值、投影及转换日志保存在项目中。详见[CHGIS接入](docs/CHGIS边界接入.md)、[Hartwell接入](docs/Hartwell边界接入.md)和[V0.4验收记录](docs/V0.4验收记录.md)。

## 保留的地点、史料及自然地理

- 40个地点档案、34个事件（含原专题的12个细分历史事件）；21条来源记录、47条逐字回查引文。
- [首批城市扩充](docs/首批城市扩充.md)记录现代坐标来源与精度。地点坐标为近似地区入口，原文地名证据不等于古址考订。
- 自然背景为现代Natural Earth数据：277个河流要素、234个湖泊、86个河湖/山脉/海域标签。历史时期切换不会把它们变成古河道、古海岸或古植被。
- 历史事件传统纪年和干支保留原文，数值年份为记年索引，未换算公历。连线只表示空间关系，非真实行军路线。
- URL保留时期、事件、地点、档案页签、双名及路线开关；边界资料年份选择、地图显示模式和原图缩放为当前会话状态。

## 数据复现

原始数据下载和转换脚本分别是 `scripts/import-chgis-boundaries.py`、`scripts/import-hartwell-boundaries.py`、`scripts/import-atlas-references.py`。Python依赖及缓存参数见对应接入文档。完成导入后合并资料清单：

```sh
python3 scripts/build-boundary-manifest.py
npm test
npm run build
```

新增数据由 `scripts/build-modern-correspondence.py`、`scripts/build-historical-context.py`、`scripts/import-terrain.py`、`scripts/build-physical-interactions.py` 生成，具体依赖、缓存及复现参数见各来源说明。完整自动检查现有49项，包含原文快照、坐标引用、地形瓦片、全量区域对应、自然图形原几何及占位名称修复。

## 项目结构

- `src/`：地图、边界图层、档案、原图阅读器与样式。
- `shared/`：数据约定、URL状态和繁简检索。
- `server/`：只读接口及回归检查。
- `data/catalog.json`：地点、事件及史料。
- `data/evidence/`：原始快照、下载文件及校验记录。
- `public/data/boundaries/`：可直接读取的历史区域GeoJSON和清单。
- `public/data/atlas/`：完整纸图影像及来源清单。
- `public/data/modern-correspondence.json`：所有已接入历史区域的简体名称与现代空间参考。
- `public/data/historical-context.json`：历史地理和城池大事记及引文来源。
- `public/data/terrain/`：本地真实高程PNG、完整来源署名与校验清单。

本地原型需要WebGL；尚未加入编辑审核后台或PostGIS数据库。GIS文件保留较多原始细节，单年份约10—35MB，当前按年份加载；新增现代名称对照约12.81MB。以后可以在保留来源数据的基础上另做矢量瓦片和按年份拆包优化。地形模式、历史地理条目和边界资料选择暂不写入分享URL。
