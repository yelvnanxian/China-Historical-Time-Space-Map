## V0.12 县域来源冲突与山系分布

- **唐城县与吉阳县**：截图中的点是CHGIS治所，面是Hartwell近似县域，面内文字只是排字位置。唐城县、湖北吉阳县在741年也已位于同名模型之外，距模型最近边缘约8.86、2.33千米；不是新增重复县，也不能简单归因为年份不同。
- 对1,365个县治与1,495个县面做全量核查。248个县治在同名候选模型外；模型侧205个满足唯一候选、跨年可比条件，32个存在歧义。存疑面显示虚线，保留原点原面；同名面外不能当作已确认的辖区。县治跳转拒绝歧义模型和已匹配另一同名县的模型。
- 重点县的简体建置说明引用《旧唐书》固定修订：唐城738年分枣阳置、天宝属汉东郡；湖北吉阳属安陆郡；海南吉阳另属临振郡。搜索结果同时显示来源位置或现代地区，避免两处吉阳混淆。
- **直接看山系区域**：使用52条Natural Earth山地命名原面，排除10个高原源类，以淡绿山纹保留底层起伏；选中加强纹理、柔和外沿及走向示意。秦岭、太行、祁连、天山、大别山等在常用全国视野可见，左上入口可收起，局部视野也能显示相交山系名称。
- 山川模式可以点山地概括区域；全部模式只有山系名称、入口和具体山脊等地物接受山地选择，山系面不抢行政区点击。城池/河流模式保留基础山纹，隐藏山地名称并禁用山地点击。
- 山纹来自1:1000万命名概括面，不是精确山脚界线、处处为山的证明或唐代地貌复原；未取得横断山、长白山对应命名面，未用其他高原范围替代。原始几何未平滑、扩张或重绘。

- 在“地图工具”的“黄河改道”中选择年代，或让河道随朝代变化；用“叠加对比”显示另一时期的棕色虚线。已接入前602—11、11—1048、1048—1128、1128—1368、1368—1855五期图集河道，唐代采用11—1048年资料。已加载的历史河道替换现代黄河下游，黄河上游及其他河湖仍是现代参照。
- 历史河道来自 WorldMap / pkbol_worldmap 的数字化资料，11—1048年等图层原说明依据《黄河流域地图集》。保留来源顶点、元数据和下载哈希；表示中下游历史流向，不是逐年河岸、水域宽度或完整河网。交界年采用新时期图，未收录年份显示现代参照并提示。

- 展开“细节区域与来源”可进入**关中与秦岭北麓、洛阳与豫西、中原与淮北、南京皖南与江淮、太湖与长江口、浙江中北部**。V0.9原六区域共有**178,372个去重现代地物**（V0.10扩至32个采集区、213,897个），包括河流、溪流、运河、水面、山峰和山口。8级起加载主河与较大水面；10级起加载视野内局部细节，溪流和较小水面从10.5级、山口从11级、最小水面从12级显示。未覆盖地区继续使用概览数据。

## 看边界与查行政区

- 在朝代选择器中选择唐、宋、元、明、清，地图加载该朝代已有资料；“行政边界”卡片单独标明资料年份，年份与页面截面不同会提示。
- 点地图右下工具按钮，展开“行政边界”。默认“随缩放自动”：4级起看省道，5.4级起看府州，6.6级起看县域；较低缩放级别看已有国家/诸部。唐资料缺少完整唐国界，全国视野以已有省道和周边诸部作范围参考，并提供完整纸图入口。层级始终跟随缩放，无需手动选择。
- 点选可见行政名称或区域，高亮来源几何表示的辖区，并查看简体名称、原文名称、现代参考地区、年份和来源。可在“查找当前资料中的行政区”输入“蓝田”“西安市”等古名或今名；选结果会定位并持续高亮对应辖区，背景层级仍随缩放改变。开启古今对照后，标签同时显示简体古名与今地参考。县域面不等于古城墙范围。
- 地图左下方“历史地图原图”提供18张完整扫描图，覆盖11个时期；可选择图幅、放大、拖动、适配全图和按Esc退出，保留国家/政权范围及原图图例。
- 历史区域、自然地物的标签、悬停、检索结果和标题统一用简体中文；原始名称收在折叠来源中。已核对163组自然外文名及20条历史外文/注音名称；1条历史名称、21组自然名称尚未核定，用中文“未定名”提示，原本无名的116组自然对象仍保留无名状态。
- 普通地点档案共106个，唐时期有104个阅读入口；地图按缩放自动显示城池点，“本朝名城”可查全部本朝入口。同一地点可显示古名与现代对应地区。“观山河”播放功能保持取消。完整层级规则见[地图缩放层级与辖区交互](docs/地图缩放层级与辖区交互.md)。

## 地图展示与交互

- 顶栏“点选”分为“城池、山川、河流、全部”，仅筛选名称、搜索与可点击对象。底图河湖、山脊、城池基础点和行政线保持显示；关闭地图工具后设置继续生效。
- **山系显示概略分布与地形**。淡绿山纹使用来源命名面，点名称或搜索结果高亮整片概略分布及主走向示意；精细山影和等高线另按采集覆盖加载。高原、海域仅提供名称与位置参考；除已注明时期的黄河图集线，河流和湖泊使用现代参照。
- **全部模式优先点具体地物**。河线、湖面、山脊和峰点优先于行政面，只有空白区域按当前缩放层级选行政区；名称可直接打开对应详情。其他三种模式只允许该类点选，避免查河时被城池或行政面截走。同一次点击只处理一个目标。
- 在“地图工具”查找“秦岭”“黄河”“青海湖”，可按类型筛选。黄河、长江已收录的多个河段联动高亮。点击行政区后，工具优先显示该区域资料。山川或河流筛选下复位返回中国及周边区域。
- 原始自然资料仍保留581条图形、540个检索分组供追溯；这些不是581个独立且都有中文档案的自然地物。其中51个山系有走向示意，1个仅保留名称。山系走向由原始命名多边形的内部截面推导，**是制图示意，不是实测山脊、山体边界或登山路线**；不适合推导的对象只保留名称。不依据这些线宣称复原历代地貌。
- 七步新手引导介绍朝代、点选筛选、自动缩放辖区、黄河对比、唐代治所、河湖与山脊细节及来源区别。首次可跳过，完成或跳过后本地记住，可从“使用帮助”再次打开。“本朝名城”入口与本朝看点方便从代表城市开始阅读；仍为精选内容，未收录不表示该城当时不存在。
- 安史之乱专题保持移除，原历史事件仍可检索；宋代“00”继续按同源下级记录修复显示为“山东西路”，原始数据不改写。

- **历史地理**：地图底栏入口提供8条跨时期条目，涵盖1128、1855年黄河改道、1938年花园口决堤与1947年堵口，以及邗沟、都江堰、隋代运河。可查看影响、原文和出处并定位地区参考点；故事点不表示完整河道或工程范围。V0.9另接入上文所列五期黄河图集线，未覆盖的河道与工程不补画。

| CHGIS V6 | 1820 | 32个省级/大区域、320个府级区域；本次未取得县面 |
| CHGIS V6 | 1911 | 27个省级/大区域、381个府级、1,986个县级区域 |
| 《中国历史地图集》纸图影像 | 各图独立年代 | 18张完整扫描图，11个时期，约28MB |

合计7个GIS资料年份、25层、12,111个区域面。数量是各年份、各层级的记录总数，包含重复时期及上下级重叠，不是12,111个独立城市。没有用点连线、平滑手绘轮廓或拼合现代行政区来冒充本项目考据出的国界。

Hartwell来源本身是以现代县界构造的近似历史行政模型，不能称为已逐段核实的历史疆界；741/742、1290/1280等来源年份存在不一致，采用实际文件年份并保留说明。CHGIS部分原始年份字段冲突、拓扑修复和基准转换精度均有记录。行政区面不等于古城城墙，也不自动等于完整国界；完整政权图通过原图阅读器提供，不将未配准的纸图强行套到交互底图。

原始资料、来源ID、下载校验值、投影及转换日志保存在项目中。详见[CHGIS接入](docs/CHGIS边界接入.md)、[Hartwell接入](docs/Hartwell边界接入.md)和[V0.4验收记录](docs/V0.4验收记录.md)。

## 保留的地点、史料及自然地理

- 106个地点档案、34个事件（含原专题的12个细分历史事件）；目录有79条来源记录。本朝看点另整理59个文本来源、347段逐字摘录，与目录来源部分重合。
- [首批城市扩充](docs/首批城市扩充.md)记录现代坐标来源与精度。地点坐标为近似地区入口，原文地名证据不等于古址考订。
- 全国自然概览为现代Natural Earth数据：277个河流要素、234个湖泊、86个河湖/山脉/海域标签；唐代32个水系采集区及5个山地采集区放大后另加载OSM细节。历史时期切换不会把这些现代数据变成古河道、古海岸或古植被，黄河历史图集线另有明确年代和来源。
- 历史事件传统纪年和干支保留原文，数值年份为记年索引，未换算公历。连线只表示空间关系，非真实行军路线。
- URL保留时期、事件、地点、档案页签、双名及路线开关；边界资料年份选择、地图点选筛选和原图缩放为当前会话状态。

## 数据复现

原始数据下载和转换脚本分别是 `scripts/import-chgis-boundaries.py`、`scripts/import-hartwell-boundaries.py`、`scripts/import-atlas-references.py`。Python依赖及缓存参数见对应接入文档。完成导入后合并资料清单：

```sh
python3 scripts/build-boundary-manifest.py
npm test
npm run build
```

新增数据由 `scripts/build-city-profiles.py`、`scripts/build-mountain-directions.py`、`scripts/build-modern-correspondence.py`、`scripts/build-historical-context.py`、`scripts/import-terrain.py`、`scripts/build-physical-interactions.py` 生成，具体依赖、缓存及复现参数见各来源说明。自动检查包含唐朝完成清单、简体名称、繁简检索、地域筛选，以及原文快照、坐标引用、地形瓦片、全量区域对应、自然图形原几何及占位名称修复。

V0.9的黄河线由 `scripts/import-historical-rivers.py` 导入，唐代治所和OSM资料分别由 `scripts/fetch-tang-detail-chgis.py`、`scripts/fetch-tang-detail-osm.py` 获取，`scripts/build-tang-detail.py` 按已保存原始资料转换、去重与拆包。来源快照、坐标冲突清单和几何核验报告保存在 `data/evidence/`。大事记可离线运行 `python3 scripts/build-historical-context.py` 重建；主脚本自动调用 `scripts/build-tang-timelines.py`，检查引用与原有节点后合并。

唐朝本批内容可离线重建（使用已保存快照，不重新联网）：

```sh
python3 scripts/build-tang-north-west.py
python3 data/tang-expansion/build-south-east.py
python3 scripts/build-tang-central.py
python3 scripts/integrate-tang-catalog.py
python3 scripts/build-city-profiles.py
```

`data/tang-expansion/completion-targets.json` 是本轮完成清单，整合脚本会阻止缺项、重复ID、断开的来源引用或不匹配的引文进入发布数据。

## 项目结构

- `src/`：地图、边界图层、档案、原图阅读器与样式。
- `shared/`：数据约定、URL状态和繁简检索。
- `server/`：只读接口及回归检查。
- `data/catalog.json`：地点、事件及史料。
- `data/evidence/`：原始快照、下载文件及校验记录。
- `public/data/boundaries/`：可直接读取的历史区域GeoJSON和清单。
- `public/data/atlas/`：完整纸图影像及来源清单。
- `public/data/modern-correspondence.json`：所有已接入历史区域的简体名称与现代空间参考。
- `public/data/historical-context.json`：历史地理和城池大事记及引文来源。
- `public/data/historical-rivers/`：五期黄河历史图集线及来源清单。
- `public/data/tang-detail/`：唐代治所、32个采集区现代地理分包及覆盖清单。
- `public/data/mountain-detail/`：真实现代山脊、陡崖和峰点分包。
- `public/data/mountain-shapes/`：17处峰顶周边的真实DEM等高线与透明山影。
- `public/data/tang-boundary-crosswalk.json`：唐755年治所与741年参考辖区的证据关联。
- `public/data/city-period-profiles.json`：11个时期的134份代表城池看点与证据。
- `public/data/mountain-directions.geojson`：只在名称选中后显示的山系走向示意线。
- `public/data/terrain/`：本地真实高程PNG、完整来源署名与校验清单。

本地原型需要WebGL；尚未加入编辑审核后台或PostGIS数据库。GIS文件保留较多原始细节，单年份约10—35MB，当前按年份加载；新增现代名称对照约12.81MB。以后可以在保留来源数据的基础上另做矢量瓦片和按年份拆包优化。地形模式、历史地理条目和边界资料选择暂不写入分享URL。

V0.10辖区关联可运行 `npx tsx scripts/build-tang-boundary-crosswalk.ts` 重建；山地由 `scripts/fetch-mountain-detail.py` 采集、`scripts/build-mountain-detail.py` 严格校验构建。详情见对应来源说明。
