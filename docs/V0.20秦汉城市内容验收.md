## 年代与来源处理

秦朝入口仍为前221—207年。前316年入蜀、前311年成都筑城、前278年攻郢与设置江陵、前249年三川郡等统一前背景在文字中明确标为秦国时期，不挪到前221年，也不重复添加既有节点。新增咸阳纪年区分前210年沙丘去世、丧车归咸阳发丧与骊山安葬，不将不同地点合为同址。

汉代入口跨西汉与东汉，默认公元2年只用于地图浏览。档案列出的后续沿革不表示公元2年已经发生；《汉书·地理志》的郡国县列表可支持记载的隶属层级，不由列序推定治所，不把郡国户口解释成城内人口。

秦新增资料使用百科固定修订。汉补充《汉书·地理志》维基文库固定修订2605705的电子转录、以及《后汉书》卷113固定修订7902259的校勘说明，并沿用或补充固定版本的百科概述。保留原始API响应、文本、获取时间、修订号与SHA-256；引文保持原字形，展示正文采用简体。固定引文可复核不代表已完成版本校勘、考古或多种史料互证。

三川郡治的洛阳、荥阳两说，以及太原郡初置年的源内冲突，均保留为明确问题；阿房宫始建的分歧不生成单一确年节点。没有可靠日期的内容保留在概览中，不用模糊年号推算精确事件。

广阳郡复置纪年依据《后汉书》校勘记：永平八年应据《和帝纪》改为永元八年，因此采用96年。节点只写恢复建置，不由县目次序或这条复郡记载推断蓟县郡治位置。另将洛阳迁都26年说、临淄封王先后、晋阳封国身份、梁园位置等存疑候选列入报告，未生成确定节点。

## 构建与保留要求

统一执行：

```sh
python3 scripts/build-reading-content.py
npm test
npm run build
```

统一入口在基础/唐、明、宋、元、清之后合并秦、汉，最终校验全部发布内容。秦汉单独构建器支持`--check`只读校验；合并仅更新各自拥有的新增ID。重复执行不得增加重复记录或覆盖此前各批。

本轮更新目录版本与说明，不变更目录地点、事件、来源或时期定义。相关行政关联等派生文件按依赖重建，并逐项核对仅校验哈希变化。地图治所坐标、行政模型、河道和山脉资料不因这次文字补充获得新的考证结论。

## 验证结果

- 完整测试260项通过，TypeScript检查与生产构建通过；最后调整一处引文支持范围措辞后，汉朝内容和历史上下文专项测试再次通过，发布数据与生产构建已刷新。
- 秦汉新增引文、来源SHA-256、固定修订链接、简体展示、年代边界与重复节点均通过校验。秦汉独立合并重复执行后，两个发布文件的字节哈希保持不变。
- 浏览器确认秦朝“本朝名城”8份、汉朝16份，秦代洛阳检索与三川郡治争议出处可读；搜索“北京”可找到汉代“蓟”，显示广阳郡复置校勘来源。
- 从秦朝洛阳的历代大事记点击东汉北宫节点，自动切到汉60年并保留洛阳；点击广阳郡复置切到汉96年并保留蓟；咸阳驰道节点切到秦前220年。URL、年份导航与选中档案一致。
- 浏览器未记录error/warn。没有增加地图固定控件；本次新增内容沿用现有检索、档案与年份交互。
