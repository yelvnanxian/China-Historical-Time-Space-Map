## P1-1 共享 JSON 下载与解析

逐项迁移：App、HistoricalMap、HistoricalBoundaryLayer、TemporalSettlementLayer、BoundaryComparison、MingJurisdictionInfo、SongJurisdictionInfo 的边界清单、治所清单、唐辖区关联、县域核查、宋明研究及古今对应；PhysicalGeographyLayer 与 TangDetailLayer 的共享自然地理索引也接入。未把原始 gzip 文件当作 JSON 加载。
