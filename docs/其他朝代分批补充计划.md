# 其他朝代分批补充计划

本计划按小批可核验内容推进。每批交付包含史料摘录、可点击纪年、数据重建和浏览器验收；已有时期资料必须完整保留。以下“下一批”是后续优先顺序，不表示尚未完成的内容已加入地图。

## 本轮：元、清首批城市文字

先复用已归档、能逐字核对的固定版本资料，元代增补长安、成都、泉州、大理、南京，清代增补西安、开封、江宁、杭州、成都、宁夏。各自关联现有城市入口和年份导航。名称、机构、港口与城市空间分别说明，元末及太平天国时期的控制权变化单列。

当前资料性质是固定修订的百科概述；引用核对不等于完成正史、地方志、考古成果的交叉考证。疑似纪年错误留在候选缺口清单中，不强定年份。此次不新增猜测的行政面或历史河道。

## 每批完成条件

- 主张能回查已取得的原文及固定版本，展示采用简体，引用保留原字形。
- 明确区分朝代阅读范围、当前年份、具体事件年份和实际政权；模糊年号不生成精确纪年。
- 只在证据支持时关联已有城市、治所或模型，不凭同名、近邻补古址和辖区。
- 新增内容能在本朝名城检索，在地点档案阅读，从纪年节点跳转年份；无依据的范围明确留缺口。
- 统一运行 `python3 scripts/build-reading-content.py`，合并唐、宋、明和后续批次后再汇总校验，避免旧基础脚本覆盖后来的增补。
