# 唐代专题史料核查

本次专题为“安史之乱”（`anshi`），覆盖 755—763 年，包含 12 个依史料顺序排列的事件节点和 10 个近似地区入口。保留原有战争总览与玄宗入蜀概览，但它们不参与专题逐节点排序。专题不是全战史、考古地图或完整行军路线复原。

## 核对方法与范围

实际通过维基文库 MediaWiki API 读取《资治通鉴》卷217—222及《旧唐书》卷9、10，共保存8份纯文本快照。快照只规范了段落空白，没有自行改字或补写缺文；同名JSON记录原始URL、API地址、修订ID及获取时间。卷219作为时间衔接背景保留，当前节点未从该卷直接摘引。

`Evidence.status: checked` 只表示本次已经在快照中核对 `supports` 所列的具体记录；`quote` 逐字匹配取得的文本。它不等于原文绝无讹误、不同史书一致或史实已获得最终定论。卷级 `Source.verification` 继续使用 `reference`，不能将整部书或整卷升为已全面核验。事件概述由项目编写，与引文分开。

专题 `dateLabel` 以原纪年为主；传统月份、干支日保存在 `HistoricalTime`。数值 `year` 只用于史书记年索引，没有转换事件的公历年份、月份或日期，不能把它当作公历发生年；传统岁末月份尤其可能跨入下一公历年。河阳攻防跨多个阶段，只标到月。史朝义自缢日未明，因此终点改为有甲辰记日和京师地点依据的“史朝义首级抵京”，不把死亡地点画在长安。756年六月的条目保留天宝十五载与《通鉴》系于至德元年的关系；763年保留《通鉴》广德元年的编年标题，不把史书全年追称的年号直接当作当天改元已经生效的证据。

## 数字文本差异

- 范阳起兵：《通鉴》卷217记“十一月，甲子”；当前《旧唐书》卷9网页相应段作“丙寅”。本专题采用《通鉴》记日，不声称两书日期互证。
- 马嵬：《通鉴》卷218作“丙申”；当前《旧唐书》卷9网页作“丙辰”，卷10相关段作“丁酉”。这些差异可能涉及原书叙述、版本或数字化文字，未据校勘本判断成因，故在对应证据注释保留。
- 成都：《通鉴》卷218七月庚辰记“上皇至成都”，《旧唐书》卷9七月庚辰记“车驾至蜀郡”；卷10八月壬午相关段又有“上皇至成都，大赦”。本专题采用《通鉴》的到达记日，不将不同记载无说明地合并。
- 睢阳：本次只互证城陷日期和地点；《通鉴》另叙许远被送洛阳、死于偃师，与《旧唐书》纪的简括叙述不可直接合成同一条死亡定位。

## 地点核查与空间精度

10个地点均附独立原文证据：范阳、长安、洛阳、潼关、成都、马嵬、灵武、睢阳、相州、河阳。证据支持名称出现或事件关联；全部 `location.accuracy` 为 `approximate`，`location.sourceIds` 留空，明确没有能为现代坐标背书的空间来源。

尤其不能把唐灵武直接等同于今天灵武市中心，把唐相州/邺郡与三国邺城遗址等同，或把“范阳”在不同叙述中的县、郡及军镇含义统一成一个精确点。河阳仅以孟州—孟津沿河地区为入口，未核定三城与古黄河位置。连接线只展示地区之间的空间关系；政权边界继续为 `schematic`，没有升级为考据成果。

## 验证结果与后续

- 35条引文（包括地点证据与兼容概览）逐字回查通过，详见 `data/evidence/quote-validation.json`。
- `npm test` 22项测试通过，包含专题接口、时间精度、来源快照引文和数据引用检查。
- 12个专题事件、10个地点的ID引用与来源成员关系通过检查；史书记年索引范围为755—763；这不是逐条事件已完成公历换算的声明。
- 本次没有完成纸本版本校勘、事件全部叙述互证、历法换算、城址考古定位、地理配准及真实疆域建设。后续应优先用可靠校勘本复核上述记日差异，并独立补充可追溯的现代空间依据。
