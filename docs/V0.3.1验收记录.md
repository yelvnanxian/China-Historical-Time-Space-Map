# V0.3.1 验收记录

日期：2026-09-24。对应反馈：边界失真、地点覆盖不足，以及暂时放弃“观山河”。

## 已完成的调整

- 地图移除手工政权色块、折线、政权标签和图层开关。页面明确提示“历史边界待核定”。真实历史国界、行政界和古城范围仍未提供；此次是撤下失真示意，不是已完成真实边界替换。
- 移除播放、时间滑块和自动推进；保留朝代下拉选择、搜索、地点档案及普通事件列表。
- 新增陕州、郑州、滑州、怀州、恒州、贝州、平原郡、鄜州、潞州、邓州、许州、徐州。全库地点40个，唐代37个；默认显示当前时期全部已收录地点，安史之乱专题仍可单独筛为10个关联地点。
- 古今地名并列显示，点击查看已收录截面的称谓和来源。新增地点的现代坐标均明确为近似地区入口，未称精确古城址。
- 地图自动适配窗口尺寸变化，手动平移或缩放后保留读者的视野；复位按钮重新纳入当前显示的地点。

## 数据核对

21条来源记录，47条已核对引文均能逐字回查本地原文快照。新增12个现代坐标与原始记录数值一致，5个来自Natural Earth，7个来自GeoNames；来源ID、取得时间及许可均留档。详情见[首批城市扩充](./首批城市扩充.md)。

原文核对支持所列名称和事实，不支持精确城址、完整改名年表或历史边界。新增唐代通行称谓不代表已逐年核定755年当时的州郡名称。

## 页面检查

- 唐代默认显示37个地点，切换“专题地点”为10个；切换宋代正常显示其20个已收录地点。
- 实测搜索“郑州”能打开新增档案、显示引文与近似位置说明，并正确退出不包含该地点的专题。
- 开启古今对照后，地图同时显示“郑州 / 今·河南郑州地区”；称谓表可展开，URL保留地点和对照状态。
- 专题事件按钮打开12条事件列表，页面没有播放或范围滑块。
- 390×844移动视口下，页面宽度与滚动宽度均为390px，地图高615px，无横向溢出。从桌面缩窄后，37个地点坐标均位于地图视口内；标签拥挤时隐藏部分文字，可缩放或搜索查看。
- 桌面地图保留全宽布局；未绘制旧政权轮廓。自然河湖和海岸仍为现代地理背景。

## 自动检查及限制

`npm test`：25项通过，包含目录一致性、API、搜索、URL状态、专题日期和原文引文回查。新增12地点的55次古名、今名及别名检索检查通过。

`npm run build`：TypeScript检查和生产构建通过。Vite仍提示地图包体较大，后续可拆包；本轮未把资源体积优化扩展为额外任务。

生产预览已在 `http://127.0.0.1:3001/?modern=1` 启动，并在浏览器确认V0.3.1、37地点选择器和地图正常显示。移动视口测试后已恢复默认窗口尺寸。

本轮没有接入新的历史边界数据。已调查候选的年代、来源缺口和下一批城市工作量见[边界与城市优先级调整](./边界与城市优先级调整.md)。后续先验证一个有出处的历史范围样本，再扩展；不恢复已取消的播放功能。
