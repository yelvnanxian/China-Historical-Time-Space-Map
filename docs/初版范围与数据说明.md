# 初版范围与数据说明

本版是供评审的可交互初版，不是已考订完成的中国历史地图。按两份 V0.1 文档，先跑通“选择时期 → 地图变化 → 点击地点 → 查看事件 → 追溯书目”的闭环。

## 已交付的数据范围

- 11 个代表截面：秦 −221、汉 2、三国 230、晋 280、南北朝 500、隋 609、唐 755、宋 1200、元 1330、明 1582、清 1820。
- 16 个政权示意区域、23 个历史地区入口、22 个事件概述、11 个参考书目入口。
- 默认唐朝 755 年；三国、南北朝及宋代截面用于演示并行政权，宋代展示南宋、金、西夏。尚未穷尽同时期所有政权。
- 每个时期的相关事件可以早于或晚于代表年份，界面应展示事件真实日期。例如唐朝 755 年专题也关联 756 年唐玄宗入蜀。事件日期变化不应被误认为已有对应年份的疆域数据。

## 真实信息、近似点与示意图的边界

详情卡优先展示简短历史概述；通用数据限制集中放在地图说明、坐标标签、来源状态及路线说明中，不逐段重复。对象本身的城址差异或地名歧义仍保留在对应概述中。

1. 事件名称、年份及人物使用常见历史叙述，但尚未逐条落实到指定版本、卷章节；所有概述由本项目编写，均非古籍原文。对于改革推广等非单日事件保留“前后”等限定。
2. 地点坐标是近似的现代对应地区入口。汉长安、隋唐长安、明清西安，以及平城、晋阳等，不能视为跨时代不变的精确城址。`nameByPeriod` 用于展示相应称谓，不代表这些城邑和行政区属于完全相同实体。
3. 所有政权多边形均为人工简化的交互示意，`certainty` 固定为 `schematic`。没有依据书目绘制真实疆域，也不表示全部领土、实际控制、争议边界或现代国界。各政权的书目链接只是背景参考，不能用来证明示意轮廓。
4. 自然背景采用现代地理资料，不是古代海岸线、河流或地形复原。底图来源见 `public/data/README.md`。
5. 都城类型按代表年份单独设置：如 1200 年的临安、金中都与兴庆府；开封不会被标作该年的南宋都城。隋唐洛阳、明代南京、元上都包含东都或陪都身份。

## 相对于 PRD 的取舍

时间导航覆盖秦至清的骨架，但只提供代表截面，不承诺逐年更不承诺逐日的完整地图。当前事件使用年及展示文字；PRD 要求的月、日、时间不确定区间、原始纪年和历法换算仍需独立时间模型。前端不能将 `year` 或时期名称解释成所有历史事实都发生在这个精确日期。

行政区图层、完整地名沿革、人物详情、路线动画、古今双地图、多时期对比和完整内容审核后台留到后续。事件中的人物名及地点中的历史称谓先作为轻量关联。安史之乱、唐玄宗入蜀提供静态的相关地点连接线，用于演示地图空间关系。线段不是史料复原的行军或出行轨迹，不代表实际道路、经过地点及精确先后顺序；未实现动态战争路线。

## 来源与许可

`data/catalog.json` 中的书目链接指向维基文库公开阅读入口；`verification: reference` 表示参考线索，不能显示为“原文已核验”。`data/source-link-check.json` 仅记录链接可达性检查，HTTP 200 也不等于事实已核验。

本版没有复制古籍原文、古地图图片或第三方历史疆域。古籍原文的权利状态与特定版本、校勘、译注、数据库及网站内容许可需要分别检查；不能因为书目年代久远就认定所有相关数字内容可自由使用。后续每条引证须补作者、版本、引用位置、获取日期和具体许可证。项目自编概述及示意数据的发布许可由项目方决定；目前不授予额外第三方授权。

- [ ] 11 个时期均可切换，每个时期至少有一个地点和相关事件。
- [ ] 宋代 1200 年同时显示南宋、金、西夏；点击任一色块可看到示意说明。
- [ ] 历史名称与都城身份随时期变化，开封和临安不会被混淆。
- [ ] 事件显示自身日期，未核验书目不会被显示为已核验原文。
- [ ] 安史之乱及唐玄宗入蜀可显示静态地点连接；界面明确说明不代表实际行军或出行轨迹。
- [x] 地点、事件、书目与政权 ID 均可解析，多边形闭合且经纬度有效（脚本校验通过）。

## 尚未完成的数据工程

选择可合法使用的历史地图资料；对代表截面进行配准、描边和考证；建立地点迁址与行政实体的独立身份；补充时间精度、不确定范围和争议观点；逐条复核来源；记录原始数据与发布版本。应先抽样完成一个时期后测量人力，再估算秦至清内容建设，不能把软件开发工期视为全历史数据完成时间。
