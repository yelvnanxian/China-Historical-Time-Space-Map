# 明朝山川河流补齐记录

日期：2026-09-25。

## 原因与处理

上一轮明代补充主要覆盖城市与建置史料。地图中的精细河湖、山脊山峰、DEM等高线三个组件仍限定唐朝启用，明朝只有概览自然地理。现在唐、明均启用这些现代参照；755年历史治所独立限定在唐代，现代图形与唐代历史点的缓存、搜索和选中状态按时期隔离。

选择唐、明城市时定位至8.5级，达到主要河湖数据8级的加载阈值。10级起继续加载局部溪流、渠道和山峰，12级可查看更小水面；按视野加载，不把所有数据同时铺到全图。“城池／山川／河流／全部”仍只筛选名称与可点对象，不隐藏基础自然图形。

明朝的“地图工具”增加“河湖与山峰细节”“山脊与山峰”“山地近览”入口；山地资料复用既有五地区的14,330条OSM记录及17处DEM近览。自编说明按“所选朝代”展示，原始标签、源坐标与归档记录保持原样。新手引导同步解释唐、明的自然地理与唐代专用历史治所。

黄河仍独立随时期切换：明代1582年采用1368—1855年图集河道，唐代755年采用11—1048年图集河道。工具说明改为实际所选时期及加载状态。现代黄河下游主线及已有证据关联的水面继续遮蔽；不根据查询框把其他支流或同名水库一起删除。

## 新增实际采集

原32个采集窗口之外，新增大同、邯郸、银川、大理、兖州、南昌、桂林7处完整查询窗口及重庆东窗，共40处。内容包含御河、滏阳河、洱海、泗河、赣江等真实现代水系记录。原始OSM响应、查询、时间戳、SHA-256和来源说明逐窗归档；无名对象保留形状，不补造名称。

本次新增10,206条地物：水面6,142、河流1,352、溪流1,295、渠道723、山峰674、山口20。共用现代细节库现有224,103条地物、493个分包。记录数按源对象统计，一条河可能包含多个对象，不等于河流条数。具体采集结果与失败记录见`data/evidence/tang-detail/ming-water-expansion.json`。

重庆整窗和西窗请求在两个Overpass接口多次超时，仅东窗取得完整响应。西窗未计入已完成覆盖，保留具体缺口；即使东窗源几何延伸到窗口外，也不把它当作西窗已完整采集的证明。窗口内原始OSM数据也不保证穷尽现实中所有支流或水面。

## 数据边界

现代OSM河道中心线、水面、山峰及现代DEM是阅读历史地图时的地理参照。它们不能证明明代河岸、明代水利工程或山体的精确历史形态。1368—1855年黄河图也不是1582年逐年河岸复原。采集窗口只表示查询范围；未收录或没有名称的地物不补造。

## 验证

- 已实际验收明代华山南峰等高线、山谷与细小溪流；长涧河可点开原始来源。
- 切换城池模式后河流、山形保持显示，地物名称与点选关闭。
- 唐代工具显示1,682条历史治所；切回明代后没有唐代治所标签或搜索入口，黄河切回1368—1855年。
- 470个既有分包、历史治所与CHGIS审计文件逐项SHA-256比较一致；新增窗口未改动旧几何。
- 224,103条现代地物逐坐标、逐水面边及源标签核验通过；168项测试全部通过，TypeScript与生产构建通过（保留既有Vite大包体积提示）。
- 最终页面检查：选择南昌自动放大至8.5级，赣江分支、湖面与细节标签正常加载；图上持续标明“其余河湖：现代参照”。
