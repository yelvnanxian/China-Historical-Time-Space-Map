# 古今地名空间对照与简体字

已为当前25层、12,111个历史区域建立独立对照表。历史GeoJSON及其全部原始属性未修改。

| 指标 | 结果 |
| --- | ---: |
| 有原名与简体名的历史区域 | 12,111 / 12,111 |
| 繁简字形转换后文本发生变化 | 8,056 |
| 有现代空间对应 | 12,100，99.9092% |
| 对应至GADM省及市/州等二级区域 | 11,940 |
| 使用geoBoundaries省级补充 | 9 |
| 域外国家级对应 | 151 |
| 明确未匹配 | 11 |
| 输出JSON | 12,808,847字节，约12.81MB |

现代对应表示**“历史面代表点所在的现代地区”**。它不证明两个行政实体相同，不是古名更名沿革表，也不表示一个历史区域的全部现代覆盖范围。例如，同为“長安縣”的不同源区域可分别对应现代西安市和赤峰市，不会按名称强行合并。

## 文件与合同

- `public/data/modern-correspondence.json`：前端读取的独立对照表。
- `scripts/build-modern-correspondence.py`：可复现的数据构建脚本。
- `server/modern-correspondence.test.ts`：独立的数据契约及回归测试。
- `data/evidence/modern-correspondence/`：原始现代面、下载清单、许可原文、覆盖及验证报告。

沿用根端合同：

```ts
{
  version: string;
  sources: { id: string; title: string; url: string; note: string }[];
  entries: {
    [boundaryId: string]: {
      historicalName: string;
      simplifiedName: string;
      modernNames: string[];
      method: "representative-point";
      note: string;
      sourceIds: string[];
    };
  };
}
```

附加字段提供核查信息：`matchStatus`、`matchLevel`、`representativeCoordinates`、`historicalYear`、`historicalDatasetId`、`historicalLayerId`、`referenceYears`、`modernRegions`、`unmatchedReason`。`modernRegions`保留源区域ID、源要素序号、原建制类型及来源。顶层`statistics`给出整体和逐层覆盖。

`historicalName`逐值复制历史面的源显示名；`simplifiedName`通过OpenCC `t2s`生成；两者均不是`modernNames`。历史来源通过`historicalDatasetId`关联原边界清单。所有旧文件SHA256存入覆盖报告，已验证一致。

## 实际使用的现代数据

| 来源 | 本地原文件 | 记录数 | 年份及坐标依据 |
| --- | --- | ---: | --- |
| [GADM 4.1中国省级面](https://geodata.ucdavis.edu/gadm/gadm4.1/json/gadm41_CHN_1.json.zip) | `gadm41_CHN_1.json.zip` | 37 | 2022版；GeoJSON显式声明OGC:CRS84 |
| [GADM 4.1中国二级面](https://geodata.ucdavis.edu/gadm/gadm4.1/json/gadm41_CHN_2.json.zip) | `gadm41_CHN_2.json.zip` | 368 | 2022版；GeoJSON显式声明OGC:CRS84 |
| [geoBoundaries CHN ADM1](https://www.geoboundaries.org/api/current/gbOpen/CHN/ADM1/) | `chn-adm1.geojson` | 34 | 元数据表示2019；固定仓库版本9469f09；CRS84 |
| [Natural Earth国家/地区面](https://github.com/nvkelso/natural-earth-vector/blob/ca96624a56bd078437bca8184e78163e5039ad19/geojson/ne_10m_admin_0_countries.geojson) | `ne-countries.geojson` | 258 | 5.1.1版，固定commit；CRS84，1:10,000,000 |
| [OpenCC Python实现](https://github.com/yichen0831/opencc-python) | 运行时依赖 | — | `opencc-python-reimplemented 0.1.7`，`t2s`配置 |

CRS84表示WGS84经纬度，坐标顺序是经度、纬度。本次没有使用未经确认的GCJ-02数据，也没有把高德/百度坐标直接当WGS84。

GADM的2022是4.1版文件时间，不代表每条边界都在该年核验，更不表示2026实时区划。省级文件的37是源记录数，含同名省份分区及特殊区域，不能说成37个省。二级文件包括地级市、自治州等，也含香港区级记录，不能把368条统称为368个地级市。原建制类型另存`sourceType`。

GADM优先取`NL_NAME_1`、`NL_NAME_2`的第一个本地名变体并转为简体；保留源记录ID。香港、澳门省级源字段缺中文名时使用明确的显示翻译。源层有20条香港/澳门二级记录缺中文名，算法保留其英文名；当前12,111条历史面没有命中这些记录，故本次实际输出的现代地名全部为中文。

geoBoundaries只作省级补充，英文省名采用代码中明确列出的中文显示对照表。其源字段把广东写成`Guangzhou Province`，显示名改为“广东省”，原始GeoJSON不改，翻译表及该源问题已记录。9条省级补充包括7条台湾相关区域、1200年復州和1911年遂溪县；后两条说明较细GADM源面没有覆盖代表点，不应把补充省界当作精确的市级对应。

Natural Earth提供的151条域外对应为：蒙古国130、俄罗斯19、哈萨克斯坦2。只显示国家/地区级，不编造其省市。

## 空间查询与未匹配

每个历史区域直接采用其现有`labelCoordinates`。依次查询：

1. GADM二级面；命中后按`GID_1`记录关系附加所属省。
2. GADM省级面。
3. geoBoundaries省级补充。
4. Natural Earth国家/地区面。

使用Shapely空间索引及点与面相交判定，边界上的点可保留多个命中，名字只去重，不擅自选最近地区。原现代面有无效拓扑时，只在运行时`make_valid`；修复索引保存在报告，原文件不改。未引入坐标位移、近邻匹配或人为选点。

11条未匹配：

- 1391年連江縣1条，代表点`119.937962, 26.146136`未被载入的现代面覆盖，涉及近海/岛屿或源几何缺口。
- 1820省层5条：万里长沙、千里石塘、曾母暗沙、东沙、中沙。
- 1820府层5条：万里长沙、千里石塘、东沙以及原图未命名的记录2106、2105。

未匹配记录保留空`modernNames`、`matchStatus="unmatched"`、`unmatchedReason="water-or-source-geometry-gap"`及明确说明。已逐点检查所有4组现代参考面的全部多边形，确认并非遗漏查询。这里不据“没覆盖”推断领属，也不伪称已经证明是纯海域；小岛缺图与海岸精度差异同样可能造成未匹配。

## 未采用的数据与来源质量检查

曾检查geoBoundaries CHN ADM2。它的元数据虽然叫ADM2，实际声明“County Level”，共2,391个县级记录，不能冒称地级市。源县界DBF中第0条`ENAME=mohexian`，GeoJSON亦标`Mohexian`，但中文`NAME=南充市`、`GB1999=440825`，显然不能直接作为漠河对应的中文名使用。因此没有把该县层或其中文字段纳入对照结果，改用GADM本地名。

上述原始文件、GitHub源commit和问题示例保留为审计证据，见`rejected-source-findings.json`。它们不是当前匹配输入。实际使用的文件均列于`download-manifest.json`并保存SHA256。

## 验证结果

- 新增5项Node测试通过：全量历史面覆盖、原名/代表点保留、来源与统计一致、同名长安县按地理位置区分、岛礁不猜配、旧GeoJSON哈希不变。
- 独立空间复核12,111条记录中的24,040个被选择的现代区域，全部包含相应历史代表点；省级父关系也没有出现代表点落在父面之外的情况。
- 11个未匹配点分别对所有现代面检查，仍无命中。
- 实际来源坐标均检查为CRS84。

报告：`coverage-report.json`、`spatial-validation.json`。逐层覆盖报告和完整未匹配ID可机器读取。这里的99.9092%是空间匹配覆盖率，不是历史考据正确率。

## 本地复现

```sh
python3 -m venv /tmp/map-modern-runtime
/tmp/map-modern-runtime/bin/pip install shapely==2.1.2 opencc-python-reimplemented==0.1.7
/tmp/map-modern-runtime/bin/python scripts/build-modern-correspondence.py --offline
npx tsx --test server/modern-correspondence.test.ts
```

离线模式要求证据目录中的文件与下载清单SHA256一致。去掉`--offline`会按保留的来源URL补下载缺失文件并校验，使用`.part`续传且不修改历史边界文件。

GADM许可为学术及其他非商业使用，许可原文保留在`gadm-license.html`；geoBoundaries本次省层元数据声明Public Domain；Natural Earth为Public Domain。本次是在用户已说明的个人非商业本地用途内生成对照，原现代面留在证据目录，没有把它们打包为新增公开地图图层。
