# 按年份筛选历史治所

地图治所层现按浏览年份筛选 CHGIS V6 官方时序点。仅在 `BEG_YR <= 浏览年份 <= END_YR` 时显示、搜索或点选该条记录；不再把固定755年唐代点或1200年宋代点沿用到同朝代的所有年份。

本轮没有新增伪造坐标或从行政面中心生成城镇。点几何、原始名称、类型、存续年、日期规则和完整来源记录均可查。

## 来源、筛选与覆盖

复用 `data/evidence/tang-detail/chgis/` 已归档的县级、府州级 WGS84 时序源包：

- [CHGIS V6 Time Series County Points](https://doi.org/10.7910/DVN/Q9VOF5)：10522行。
- [CHGIS V6 Time Series Prefecture Points](https://doi.org/10.7910/DVN/WW1PD6)：5226行。

15748条原始记录中，14862条区间通过基础校验，886条隔离。隔离理由可重叠：坐标属性与SHP相差超过0.02度829条、无效起讫区间28条、单年切片规则与起讫区间冲突20条、无效坐标10条、未核定中文名称1条、超出资料历史年代范围的终年或起年2条。后两类异常包括11911年等源值，未擅自改为1911年。

11个时期包共包含14778条不同源行；另84条有效区间不与当前收录的朝代窗口相交，保留在审计清单，不硬塞入相邻朝代。一个长存续区间可以进入多个朝代包，但同一包内不会重复发布同一源行。

清代多数记录在1911年截止；浏览1912年只显示少量原文覆盖该年的记录，不能把1911年资料自动延长。零年不参与筛选。公元前年份以“前N年”显示，原始负数存续年保持不变。

## 身份与定年

记录ID包含源文件层级、`SYS_ID`及原始行索引。府州源包中的 `35000`、`35001` 各有重复SYS_ID；本轮均保留独立行，没有按记录号、名称或坐标吞掉原始记录。同名同类型记录在当前年份并存时，详情提示可能为异地同名或来源时序重叠。

日期仍分为明确端点、宽时段端点、缺失或未定义规则。显示“时序候选”而不声称已经逐年考定：

- 明确到年、月或日的端点，也不证明整个区间内每年无争议存在。
- 朝代、跨朝代或年号规则保留为宽时段，不补造精确日期。
- 缺失规则的记录按原始起讫年筛选，并显式提示待核。
- 规则9定义为单年切片；起讫年不同则隔离。

因此755年比旧固定唐代包少1条：阆中郡源编号 `211282` 的切片规则与区间冲突，现隔离。未改画或移动任何点来填补这一差额。

## 辖区关系严格按年份使用

**1200年**：保留既有20条经审核的源记录、史料身份与辖区关系，封装在 `documented1200`。只有浏览年1200且源记录当年有效时，才显示其政权、参考范围及目录档案入口。1199、1201及其他年份不能继承这些关系。

**755年**：沿用既有唐代治所关联和县治诊断。1023个当前有效源点可回到已有府州参考关联，县级匹配、存疑范围、逐字研究与来源诊断按原有逻辑保留。入口明确区分755年治所与741年模型，查看范围由上层统一切换至741年，不能将其称为755年精确边界。县治诊断同时核对源ID和坐标，避免新记录误用旧诊断。

**其他年份**：不套用上述两个固定年份的关联，不将最近行政面或上级范围当作当前年份的同级辖区。治所原始记录仍可浏览。

## 地图交互与加载

府州级源点从6级显示，县级源点从8级显示。实际行政类型单独展示；羁縻州、军、监等不会因所在文件被统称为县或府。

“城池”和“全部”模式显示名称并允许点选；“山川”“河流”模式关闭治所名称与交互，点形保留为淡背景。搜索先按年份筛选，再匹配古名、今录位置、源编号；搜索无结果不能证明当时不存在城镇。

朝代包使用确定性gzip，单包约52—426KB。浏览器同时兼容服务器已经解压和直接返回gzip两种方式。切换年份只在已加载包中筛选；切换时期按需加载并中止旧请求，内存最多缓存两包。旧时期数据在新包加载期间不进入显示或搜索。

绘图只向MapLibre提交ID、源层级和几何，证据在详情数据中保留。缩放集合只在6、8级阈值改变；标签按视野避让，最多100个，避让不会删掉原始点。未收录时期不显示治所面板或套用相邻时期数据。

## 文件、重建与验证

- `shared/temporal-settlements.ts`：类型、年份有效性、搜索和固定年份关系门控。
- `scripts/build-temporal-settlements.py`：全时序筛选和分包。
- `public/data/temporal-settlements/manifest.json` 与各朝代 `.geojson.gz`：发布数据及输入、输出哈希。
- `data/evidence/temporal-settlements/selection-audit.json`：所有源行接纳或隔离结果、原始异常字段、哈希。
- `data/evidence/temporal-settlements/period-definitions.json`：仅保存分包所需的时期名称与年份定义，避免无关目录文字变化使源点哈希过期。
- `src/components/TemporalSettlementLayer.tsx`：按浏览年份显示的治所图层。
- `server/temporal-settlements.test.ts`：独立读取ZIP、DBF和SHP的验证及年份回归。

依赖Python 3标准库、Node.js及项目现有npm依赖，无需GIS Python库或联网。脚本复用已有宋代导入器的原始点读取函数，不修改旧宋包、唐包或原始ZIP：

```sh
python3 scripts/build-temporal-settlements.py
npx tsx --test server/temporal-settlements.test.ts
npx tsc --noEmit
```

如果1200年的审核关系有改动，应先按既有顺序重建宋代建置研究与宋治所包，再执行本脚本；若时期起止年发生变化，也须重建分包。

验证覆盖全部15748源行的归属、14778已发布行的原始坐标与字段、886隔离条件、11包时间交集与代表年计数、改名起讫端点（例如1189年重庆府）、无零年、同名保留、755年旧核查入口、1200关系不跨年，以及全部源文件与gzip包哈希。
