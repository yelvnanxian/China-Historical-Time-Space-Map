# V0.8 验收记录

版本：0.8.0。任务：统一简体中文地名、持续补齐本轮唐朝主要城镇清单并推送。

## 交付内容

- 地名：25层12,111条行政记录、23,572项现代参考名称、540组自然地理（581个要素）及51条山系走向的可见名称，统一经过中文/简体显示解析。原文可折叠查阅，原名仍可搜索。
- 历史外文及注音名称21条中，20条有据转换、1条待核定；自然外文184组中，163组有中文对应、21组待核定。待核定名称使用中文提示，不按拼音猜名。来源原本无名的116组保留未命名状态。
- 唐朝：104个阅读入口清单全部完成，新增66个地点，增加咸阳唐代关系；299段逐字摘录，每条至少2段。目录共106点，本朝看点共134份，其他朝代30份原内容保留。
- 名城菜单增加古名、今名、别名和繁简字搜索，以及9地域筛选、条数、空状态及重置。新增州府显示755年郡名并附常用州名，详情解释名称与年代。
- 原有山川选取规则、可折叠控件、新手引导及专题移除状态保持有效。

## 核查

- `npm test`：67项通过，含全量名称审计、清单完整性、引文匹配/来源SHA256、近似坐标来源、时期关系、搜索和区域筛选。
- `npm run build`：通过类型检查和生产构建。仍有既有MapLibre/OpenCC主包超过500KB的体积提示，不影响构建；未把此提示记作零风险。
- 数据构建重复执行输出相同；已有30份非唐档案、事件、时期和政权完整保留。地图原始输入30份哈希无改变。
- 浏览器：1280×850、390×844与生产版360×800检查名城菜单、列表滚动、繁体“蘇州”→“吴郡（苏州）”、今名“南京”→江宁、地域交集空结果、西域13条筛选、龟兹详情及URL定位、跨朝代筛选重置。
- 键盘：清空搜索、重置筛选后回到搜索框；Escape收起并恢复入口焦点。
- 浏览器：原名“Tuotuo”检索显示沱沱河，标题与地图标签一致；“Yinshui”检索显示溵水县，详情显示中文类型与来源；明代楚雄府、奴儿干都司能用中文查找。默认折叠来源原文。

## 统计口径与边界

104按城镇阅读入口计数，幽州/范阳沿用同城不同入口，包含关隘、驿站及同期南诏城邑；不是104个独立且已考证的古城遗址，也不声称穷尽唐代全部州县。

新增坐标为现代地区近似参考，未核定古城墙、迁治旧址或街道。州郡名称按年代说明，摘要覆盖整个唐代。原古籍、纸图与来源摘录保留原字形，不改写历史资料来满足显示格式。

详细清单见《V0.8唐朝城镇覆盖》，名称证据和待核定清单见《全时期地名中文显示与核查》。
