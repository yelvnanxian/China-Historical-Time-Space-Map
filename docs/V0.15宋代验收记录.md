# V0.15 宋代资料与地图验收

日期：2026-09-27。代表截面为1200年；档案中的北宋、南宋以及同期辽、金、西夏、大理史事按各自年代阅读。

## 内容规模

- 宋代入口由20个增至29个，专门档案由3份增至29份。新增苏州、济南、兖州、鄂州江夏、福州、重庆、桂林、宁波、南昌入口，复用原有地点坐标。
- 新增48条有确年依据的大事记；4个重复事件继续使用原节点，477条既有纪年保持原值。全部时期合计525条。临淄、邯郸、潼关没有本轮可确定纪年的新条目，不用笼统叙述凑数。
- 78段逐字引文来自16项固定版本来源：14卷《宋史》《金史》，以及明确标注为二手参照的大理、敦煌原有概述。原始API、文本快照、修订号与SHA256归档。
- 25个城池入口可查看同名、同层级、同时期的具名来源模型。潼关、兴庆、大理、敦煌保留未关联说明。
- 宋代开放40个现代自然地物采集窗口、5个现代山脊采集区；29个城池参考点都在已有采集窗口内，这不表示其全部河湖山地已收录。
- 新增5处现代DEM窗口，累计22处、18,451条等高线。新增窗口为杭州北高峰、南京紫金山北高峰、福州鼓山绝顶峰、泉州清源山、南昌石鼓脑附近。

## 以往问题的对应处理

| 既有问题 | 本次处理 |
| --- | --- |
| 朝代切换仍出现其他时期的城市身份 | 1200年北京为金中都，开封为金南京开封府，南京为南宋建康府；洛阳1217年改称中京不提前显示。大事记默认本期，跨朝代概览折叠并另标。 |
| 古今同名误配、府县混用 | 临安府与临安县分开；庆元府对应宁波，鄂州对应武汉武昌。晋阳旧城入口关联平晋县，不冒充太原府治阳曲。 |
| 有府郡名称却只有点，或错误套用上级面 | 城市点与府州县模型分别显示；按源ID、名称、类型、政权、隶属和文献链关联，不按最近位置猜配。没有可靠范围时说明缺口。 |
| 模型本身有错误 | 大同原类型为州、重庆仍用渝州旧名、邯郸上级写成磁府，分别揭示；原面及原始类型保留。泉州参考点落在源面外，明确标注点面存疑。 |
| 历史年份混用 | 1080年北宋辽模型与1200年南宋金模型分别提示；从城市档案查看辖区会选中1200年模型。重庆1189年升府、隆兴1163年升府采用本纪核年，地理志疑文仍可查看。 |
| 宋代山川空白、只有山影 | 开启河湖、山脊、等高线详细层；城市定位到9.5级，已收录窗口直接显示等高线。新低山窗口采用50米等高距、250米主线；同名北高峰附地域区别。 |
| 河流改道只换标签 | 宋1200年使用1128—1368年黄河图集几何，可与1048—1128年北宋河道叠加比较。河道年代独立于行政模型年份。 |
| 点选筛选改变底图或误点城池 | 保持自然图形，只筛选名称与可点对象；查看辖区的明确操作恢复城池模式。唐755年治所不能出现在宋代。 |
| 分享后没看到详细地形 | 有效城市分享链接直接打开档案并定位；无城市参数仍从总览进入。 |

## 资料边界

Hartwell边界仍是来源提供的近似模型，不是逐段核定的1200年精确国界、府县界或城墙。现代OSM、DEM和概略山系面明确作为现代参照，不能据此复原宋代湖岸、山脚或水库。历史黄河线保留来源顶点与独立分段，没有平滑补绘缺失河段。

新5处DEM窗口的负高程保留在原始瓦片中，显示时排除非正值等高线并遮蔽相邻异常山影，不把低值填平。原17处窗口的几何、元数据及源哈希保持原值。DEM反采样核验只验证计算过程，不等于测绘精度。

## 复现与验证

宋代内容离线构建：

```sh
python3 scripts/build-song-content.py
npx tsx scripts/build-song-boundary-research.ts
python3 scripts/audit-song-natural-coverage.py
```

`scripts/fetch-song-sources.py`用于获取固定修订；已有快照可离线使用。地形生成和验证命令见[宋代自然地理接入](宋代自然地理接入.md)。改动目录后还需依次重建`build-tang-boundary-crosswalk.ts`和`build-tang-county-diagnostics.py`，更新依赖输入哈希；此次唐代关联与诊断结果没有改变。

自动检查覆盖逐字引文、固定版本与双快照哈希、名称年代、府县关联、旧资料保留、唐治所隔离、宋黄河几何及DEM来源。`npm test`共181项通过，`npm run build`与`git diff --check`通过。

浏览器实测临安、建康、泉州9.5级山形与河湖可见；建康等高线可查看250米海拔和真实来源。城池模式隐藏自然名称但保留河湖、等高线。另核查城市分享定位、临安府范围、1080/1200切换、名城繁简搜索、泉州点面提示及资料缺口。生产构建仍有既有的大体积JavaScript分块提醒。
