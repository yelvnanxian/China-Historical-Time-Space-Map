# V0.1 初版验收记录

此文保留 V0.1 的验收结果；当前版本的结果与限制见 [V0.2 验收记录](V0.2验收记录.md)。

日期：2026-09-24。范围：本地 Web 交互原型，不含历史疆域学术核验。

## 自动检查

- `npm run build` 通过：TypeScript 与 Vite 正式构建成功。
- `npm test` 通过：10 项测试覆盖真实 HTTP API、古今地名与公元前年份搜索、历史名称对应时期、详情关系、坏数据校验、生产页面路由与错误响应。
- 依赖安装审计为 0 个已知漏洞。MapLibre 已使用 6.11.1，并显式配置 Vite worker 打包。

## 浏览器验收

在 Codex 内置浏览器检查桌面窗口与 390×844 窄屏：

- 正式构建启动于 `http://127.0.0.1:3001`，唐代首页出现 20 个地点标记，生产页面未捕获 JavaScript 错误。
- 唐代切换宋代后显示南宋、金、西夏三个示意区域；长安由都城切换为城邑。
- 搜索“大都”跳转元代并显示大都档案；“公元前221年”可找到秦统一事件和秦代截面。
- 播放会自动切换历史截面，暂停后恢复播放按钮。
- 点击地图上的长安准确打开长安档案，隐藏文字的邻近圆点不再截获文字点击。
- 地点图层关闭后 DOM 地点标记归零，开启后恢复。
- 安史之乱详情提供相关人物、地点、路线显示开关及《资治通鉴》《旧唐书》参考入口。
- 事件到史料弹窗的跳转正常，参考文献和待逐条核验状态清楚可见。
- 窄屏无页面横向溢出，内容依次为地图、可横向滚动的时间轴、地点档案。
- 本地底图、字体回退和 MapLibre 工作线程不依赖地图 API 密钥。

## 尚未完成

- 政权几何为简化示意，地点为地区近似入口，尚未逐条考证；河流和海岸线是现代自然地理背景。
- 时间轴仅提供 11 个代表性截面，没有逐年疆域或月日级历史筛选。
- 来源目前是已检查可访问的参考书目入口，不是已核验到卷章的事实证据。
- 没有数据编辑审核后台、独立人物详情、用户系统或生产部署。
- 地图引擎的构建包仍较大；规模扩大后再按实测拆包、缓存和切换矢量瓦片。
