# V0.4 历史边界与原图接入

日期：2026-09-24。目标是直接取得可用历史地图，并把行政层级和政权范围的含义分清楚。此次实际下载、转换、接入并验证了数据；不只是候选来源调查。

线条按层级使用不同颜色与宽度，县级从放大后的视野显示。区域可以点选，也可在边界卡片内搜索并定位；支持简体输入匹配繁体源名称，名称显示不被强行替换。

另提供《中国历史地图集》18张完整纸图扫描，覆盖应用11个时期。保留原图政权/部族分界和图例，可切换、放大、拖动、适配全图及Esc关闭。它是独立原图阅读器，未配准到交互底图。唐代三幅原图分别注明669、741、820年，不能统称755年。

## 数据验证

- Hartwell 9,365个面、2,917,516个坐标位置；原始记录及96个文件组件留存，ZIP组件CRC与实际下载相符，标签点位于面内。未平滑、简化或溶解成完整国家疆界。
- CHGIS 2,746个面；77,270个源属性逐值保留，下载ZIP与官方MD5一致。输出面有效，标签位于面内，应用ID唯一；重复原始ID保留并仅追加应用行号。
- 18张图像逐一检查字节数、Git blob SHA-1及SHA-256，合计28,149,231字节。原始像素和完整图例保留；16张可读出年代，秦/西汉单年未确认则留空。
- 自动检查通过：原25项API/史料/URL回归，加边界图层数量、坐标范围、闭合环、年代及来源记录检查，以及繁简名称检索，合计28项。

## 已实测交互

- 唐代GIS层正常显示，可放大看到府县分界；地图点选“蒲圻縣”显示对应区域、741年及来源。
- 输入简体“蓝田”找到源名称“藍田縣”，点选定位并显示原始记录。未把原始上级分组当成已经考定的政治从属关系。
- 切到清代可选1820与1911，省/府/县层级按实际有无展示；1911“江宁”检索得到江宁府、江宁县，县可定位。
- 原图阅读器成功切到741年唐图，放大到150%；退出后键盘焦点回到入口按钮。
- 390×844视口下无横向溢出，原图弹窗正好覆盖390×844，图像加载成功、可放大阅读。
- 移动端清代首次加载的20个已有地点均在地图视口内；切换秦代时清除上一时期的边界数据，并明确显示当前无GIS边界，仍可阅读秦代原图。

`npm run build` 的TypeScript与生产构建通过。保留较完整的边界细节使数据量较大；单年份约10—35MB，当前本机使用已验证，未做对外部署或矢量瓦片优化。

生产预览运行在 `http://127.0.0.1:3001/?period=tang&modern=1`，浏览器已确认V0.4.0、实际边界线与标签、741年资料提示及原图入口正常显示。临时手机视口已恢复默认。

## 准确性边界

Hartwell是有明确来源的近似行政模型，来源本身使用现代县界作为构件，并非精确古界。它的少数原始拓扑问题、741/742及1290/1280年份冲突保留说明。独立政权/诸部面只来自原始分类，不把所属行政区面集合自动当成完整国界。

CHGIS 1820府层虽然官方文件标1820，但320条原始起止年均为1911；1911层另有4条局部年份异常。界面、清单和源属性都保留这些冲突。两年府层实际几何不同，不擅自把冲突改掉。1820没有取得县级面，未以1911县界或县治点冒充。

原始投影为西安1980高斯克吕格第19带，转WGS84的基准偏移精度未知。CHGIS部分源拓扑做了有记录的修复，千里石塘计算面积变化约2.63%；修复不是史学核定。古城城墙范围仍未提供；行政界、政权范围和城墙是三种不同对象。

源文件、转换细节和复现方式见[CHGIS接入](./CHGIS边界接入.md)及[Hartwell接入](./Hartwell边界接入.md)。原图出处、固定版本与哈希见 `public/data/atlas/manifest.json`，处理脚本为 `scripts/import-atlas-references.py`。
