# V0.7 用户评价（开发前基线）

2026-09-24。独立用户评价任务；只读检查源码、数据及 V0.5/V0.6 验收记录，未操作主线程浏览器、未做新的真机测试或真实用户访谈。本轮仅新增本报告。

**判断：已有探索价值，应先修点击规则和内容覆盖，再用轻引导降低学习成本。** 不宜把当前版本宣传为完整的各朝代城池地图。P1 表示影响核心任务、优先修复；P2 表示影响效率或部分人群。以下体验影响属于推测，不是假称用户访谈结果。

## 已经有效

**事实**：常驻大卡片已移入可关闭工具；三种模式可分别查看城池和自然内容；原图、史料、古今对应、真实高程都有来源及局限说明。既有 V0.6 记录确认桌面和390px布局无横向溢出。应保留这些基础，不为引导重新堆叠固定面板。

## 主要问题与验收建议

| 严重度 | 观察事实 | 体验推测 | 验收建议 |
|---|---|---|---|
| P1 点击一致性 | 自然山系面、湖面、海域和14px河流命中线优先于行政区；行政点击遇自然图形直接返回 | 点击一个历史区域却弹出山川，用户无法预测 | 同时显示：城市点选城市、自然名称选山川，其余区域仅选行政；重叠处不双选，无行政资料时不回退选自然面 |
| P1 山系表达 | 当前山系有概括填色块、虚线边框和选中面；资料本身不是测绘分界 | 容易被误读为政区、精确山体边界或山脊 | 默认和选中均撤面块/包围轮廓；名称点击只显示有解释依据的走向示意，不把面外沿改称山脉走向 |
| P1 内容覆盖 | 共40地点、34事件；唐37地点/14事件，秦8/2，其余16–21/2；大事记仅10城35节点 | 没有点容易被理解为古代没有这座城，切朝代感觉内容重复 | 每朝补可发现的代表城市与看点；记录当期名称、对象、坐标精度、来源，不能批量把同城挂满所有朝代充数 |
| P1 首次使用 | 默认唐代、同时显示；工具/档案收起，无分步引导；关于页“开始探索”只关闭弹窗 | 不知道先做什么，也不知道隐藏入口 | 3–4步轻提示，真实锚点、可跳过、可重放；不自动乱改朝代，不阻塞地图，手机锚点不越屏 |
| P2 搜索发现 | 全局搜地点/事件/时代，自然搜索藏工具内，行政搜索还需展开边界 | 主搜索无结果被误认为系统未收录 | 至少说明搜索范围并指向正确入口；用长安、秦岭、蓝田县验证，不急于重构统一搜索 |
| P2 历史可信度 | 唐/元/明边界资料为741/1290/1391，界面代表年为755/1330/1582；原文核对说明已存在 | 用户可能把所有图层读成同一年 | 保持实际资料年份、近似模型/现代背景标记可发现；“核对原文”不能泛化为地图已全面考证 |
| P2 手机操作 | 已有无溢出记录；模式按钮最小23px高、字号10px，工具有嵌套滚动 | 可能难点、难读，滚动与拖图相扰 | 360/390/430px、软键盘、横竖屏验证；主操作优先40–44px触控目标，不以无溢出代替易用性 |
| P2 分享承诺 | 仍写保存“专题”和“正在看的位置”，但URL不含自然选择、相机或地形 | 分享山川后接收者看到普通地图，以为链接失效 | 先修文案到真实保存范围；复制后新窗口核对。旧专题链接归普通地图，事件身份保留 |
| P2 键盘路径 | 标签是按钮、dialog有原生支持；主搜索仅Enter选首项，档案未显式移交/恢复焦点 | 打开内容后不易找到阅读起点和返回入口 | 检查Tab→搜索→详情→来源→关闭闭环，引导不依赖鼠标才能完成 |
| P2 复位语义 | 复位始终按当前时期城市点拟合，纯自然模式也相同 | 会回到一组看不见城市定义的范围 | 明确并验证不同模式的复位规则，避免承诺“返回刚才的位置” |

## 本轮发布前检查

1. 同时显示分别点名称、区域内部、原山系块边缘、河道旁、湖面：对象符合上述规则；无残留透明命中面抢点击。
2. 山川详情关闭、切模式、关闭工具后，图层与高亮状态一致；DEM或自然数据失败不遮挡正常底图。
3. 给出11时期补充前后清单，每朝代表城池能搜索、定位、看到当期看点及出处。资料记录数不当作独立城市数。
4. 初次提示跳过后可立即探索，重看可发现；手机引导与面板可关闭，无横向溢出。
5. 同步清理“点击山系范围”“查看完整范围”“当前专题”等过时文案。未保存的分享状态不作承诺。
