# V0.19 元、清首批内容验收

日期：2026-10-08。版本：0.19.0。按小批补充其他朝代，本轮先完成有本地可追溯资料的元、清城市文字，不宣称两朝全部完成。

## 本轮交付

| 朝代 | 原城市看点 | 本轮新增 | 当前看点 | 新增纪年 |
| --- | ---: | ---: | ---: | ---: |
| 元 | 3 | 5 | 8 | 5 |
| 清 | 3 | 6 | 9 | 13 |

元代新增长安、成都、泉州、大理、南京：京兆/安西/奉元沿革、四川行省机构、泉州港税、大理路与太和县、集庆至应天的政权转移。新增节点为大理1274、泉州1278和1281、北京1285、南京1356。1267营建开端与1285全城完工分别呈现，1356应天明确属于朱元璋元末政权，不提前视作明朝京师或仍受元控制。

清代新增西安、开封、江宁、杭州、成都、宁夏：城墙修缮、省府治、织造、八旗驻防、机械局、保路运动、书院与文献称名。13个节点分布于1650—1911年，保留原有1724宁夏节点，不重复加入。江宁/天京的政权变化、条约列为通商口岸与实际开埠、府城与县治分别说明。

所有新增档案均在“本朝名城”提供搜索、地域筛选和定位，地点详情展示原文及固定版本链接；新增纪年自动进入年份导航，点击保持当前城市并切到对应年份。档案仍概览整个时期，页面注明当前年份与整理代表年的区别。

本轮最终总量：218份本朝档案、106个城市入口的589个纪年。唐104、宋51、明28份档案保持原值。原207份档案、571个纪年、8条历史地理以及目录地点/事件/来源/时期逐项保留，核验见 `data/evidence/reading-content-v019-preservation.json`。

## 来源与未采用候选

两批分别复用6份已有固定修订快照，部分来源重合。每段新增引文在本地文本中逐字验证、匹配SHA-256，正文使用简体，引用保持原字形。来源为百科概述，并非本轮新增一手史料互证；地图参考点不能据此升级为已考定古址。

- 敦煌“乾隆三十五年（1760年）”的年号、公元年冲突，不选择其一生成节点。
- 南京“1906沪宁铁路、1911津浦铁路通车”需要分别核对开工、分段和全线节点，暂不采用。
- 杭州开埠段落混用1895条约与1896通商场，暂不加入确定开埠年。
- 1911保路运动采用原文“6月”，不将它转写为已核定的农历六月。
- 大理路、太和县与云南行省治不同；泉州市舶抽分与一般输税不同；“银川”书院、文献用名不是现代市建制设立。

未改动治所坐标、边界、河道、山脉或原图。目录仅更新版本和数据说明，其引起的派生行政关联哈希已重建；派生数据核查结论和几何保持不变。

## 可复现构建

```sh
python3 scripts/build-reading-content.py
npm test
npm run build
```

统一脚本依次执行基础城市看点、基础/唐纪年、明、宋、元、清合并，再生成最终统计。旧的基础脚本会覆盖后来增补，不能独立用于全量发布。原先滞后的134份档案/414条纪年校验报告已更新为最终218/589，与发布文件SHA一致。

元、清可独立执行 `build-yuan-content.py`、`build-qing-content.py`，或加 `--check`只核验。反复合并后两个发布文件的字节哈希保持一致，不重复节点、不覆盖其他时期。
