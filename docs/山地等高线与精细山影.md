# 山地等高线与精细山影

本层以已发布 OSM 山峰的原始名称和坐标选择 17 个近览窗口，下载 Mapzen / Tilezen Terrarium z11 高程瓦片，生成真实现代等高线和透明山影。它补充山峰点与 OSM 山脊线的地形表达，不表示山脉范围，更不是唐代山体复原。

覆盖峰点为拔仙台、华山南峰、终南山、麦积山、王屋山、王莽岭、北台顶/叶斗峰、岗什卡、疏勒南山、卓尔山、汗腾格里峰、博格达峰、雪莲峰、贡嘎山、幺妹峰、仙乃日、雀儿山。名称不改写成更知名的别称；例如拔仙台保留来源名称。`regionId` 沿用五个 OSM 采集区，只表示数据分组，不证明峰点的地理山系归属。

每个峰使用所在 z11 瓦片及周围一圈，共 3×3 张原始 PNG，形成 768×768 高程网格。实际下载 153 张源瓦片（10.08 MB），生成 11,984 条等高线、2,573,919 个顶点和 17 张透明山影（派生文件合计 25.39 MB）。地面像素间距 55.020–67.396 米，随纬度变化，清单提供每区中心和全幅像素间距；瓦片像素间距不等于独立测量精度。DEM 混合多种源资料，不以 OSM 峰高修补 DEM；OSM 峰高与 DEM 栅格最大值可能不同。

## 来源与处理

- 原始服务：`https://s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png`。
- 编码：`R*256+G+B/256-32768`，单位米。原始 RGB PNG 字节保存在 `data/evidence/mountain-shapes/dem`，每张记录 URL、获取时刻和 SHA-256。
- 等高线：ContourPy marching squares，网格边线性插值；不平滑、不简化、不手工补线。秦岭、太行及卓尔山窗口等高距 100 米、主线 500 米；其余高山等高距 200 米、主线 1000 米。发布坐标取八位小数。
- 山影：按每行纬度修正实际像素间距，计算地表法向与西北 315°、高度 45° 光照，垂直夸张为 1。RGBA 透明度仅表示低于平地光照的阴影，平地不铺色。边缘 24 像素只做透明裁切过渡，不修改高程或等高线。
- 原始归属说明沿用 `public/data/terrain/attribution.md`；Mapzen / Tilezen 资料汇集 USGS SRTM、GMTED2010 等贡献源。

原始 DEM 的王屋山窗口出现 8 个孤立负高程像素（最低 −683 米，周围约 200–460 米），王莽岭窗口出现 4 个（最低 −41 米）。仅针对所选内陆山地窗口，将这些样本标为待核源异常：清单 `excludedDemSamples` 逐点保留原始坐标、高程和排除原因，等高线跳过涉及格网，山影对应像素及邻接梯度透明；不补洞、不把负值改成零。此判断不是 DEM 提供方的无效值声明，也不适用于低于海平面的真实地形。原始 PNG 保留全部原值。

## 前端契约

`shared/mountain-shapes.ts` 定义契约，入口为 `/data/mountain-shapes/manifest.json`。每个 `areas[]` 包含实际峰点 `center`、取数 `bounds=[w,s,e,n]`、`contoursUrl`、`shadeUrl`、`sourcePeak`、逐张 `sourceTiles`、像素间距、等高距与文件校验值。

等高线为 gzip GeoJSON `FeatureCollection<LineString>`；属性 `elevation` 为米，`index` 表示主等高线，`modernReferenceOnly=true`。山影 PNG 用 MapLibre image source 的 `imageCoordinates`，顺序为左上、右上、右下、左下。矩形只用于加载和定位，不能作为山体边界绘制。覆盖外的峰不得用最近窗口冒充已有形态数据。

## 重建与核验

```sh
/tmp/map-chgis-runtime/bin/python scripts/build-mountain-shapes.py
/tmp/map-chgis-runtime/bin/python scripts/validate-mountain-shapes.py
npx tsx --test server/mountain-shapes.test.ts
```

Python 依赖为 numpy、pillow、contourpy。已有原始瓦片后可用 `--offline` 重建，不再联网。构建审计为 `data/evidence/mountain-shapes/validation.json`；独立核验将每个最终发布的经纬度顶点反投影到原始 DEM，再做双线性取样，记录于 `roundtrip-validation.json`，允许误差小于 0.1 米（只约束派生计算的一致性，不声称原始 DEM 有 0.1 米精度）。另核对所有源哈希、真实峰点名称坐标、主线间隔、范围与透明边缘。

本次全部 2,573,919 个已发布顶点反算通过，最大计算误差 0.010684 米；17 个峰的名称坐标与已发布 OSM 记录完全一致，153 个原始 PNG 哈希通过，17 张山影的外缘全部透明。三项数据回归测试通过。
