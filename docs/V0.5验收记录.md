# V0.5.0 验收记录

日期：2026-09-24。按用户四项需求，由地形、区域数据、历史内容三个子智能体并行实现，主任务接入地图和档案交互并统一验收。

## 本版结果

1. 历史地理入口：8条河道、水利、洪灾条目，支持类型筛选、出处展开及地图参考点定位。跨时期事件独立标注日期，定位不会把当前朝代或底图误改为事件年代；参考点有发生地区、受益地区或区域入口说明。
2. 古今对照：覆盖全部12,111条既有历史行政记录，12,100条有现代地区参考，11条明确未匹配；全量简体显示、原名保留，行政区搜索支持简体、繁体与现代地区名。区域标签使用“今参考”，详情解释代表点关系及资料版本。
3. 山川起伏：454张真实本地DEM、默认山影、平面/立体、横断山近览，立体夸张1.5倍；可关闭山影，DEM故障单独降级，不遮挡正常底图。
4. 城池大事记：10城35节点，按时间排序且跨当前朝代显示；每项有摘录及来源性质。未收录城池显示待补状态，仍可查看原有事件。

## 使用边界

- 当前GIS面范围没有扩充到此前无资料的朝代；本版补全的是已接入区域的文字和现代参考。12,111是跨年份跨层级记录数，不是城市数。
- 现代对应是代表点所在地区，不是古今政区等同、不列全部相交现代辖区；GADM 2022版不等于全部名称更新到2022或2026。
- 没有可靠古河道矢量时不补画推测路线；现代河湖和高程不能当作古代地貌复原。
- 地形z0–6适合区域观察，局部原始采样约1–2.4km，放大不会增加地貌精度；含海底负高程。
- 新增历史内容主要是可追溯百科概述并复用少量古籍材料，原文逐字匹配只证明摘录存在，不等于历史事实已全面考证。
- 地形与新增历史地理选择为当前页面状态，暂未写入分享链接。
