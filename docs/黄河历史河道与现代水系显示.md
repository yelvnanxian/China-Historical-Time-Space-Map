# 黄河历史河道与现代水系显示

本版按朝代代表年实际切换河道几何，另可在地图工具中手选年代、叠加另一时期的虚线。历史地理中的1128年改道事件联动对应河道，清除参考点恢复当前朝代。主图仍保留当前朝代的行政区；跨时期对比线不会改变行政资料年份。

## 来源与时间

公开向量来自 WorldMap / `pkbol_worldmap` 的 ArcGIS Feature Service。其11—1048年图层说明依据《黄河流域地图集》；每个时期自己的元数据、原始查询响应和SHA-256保存在 `data/evidence/historical-rivers/`，处理脚本是 `scripts/import-historical-rivers.py`。没有增加曲线、猜接河段或平滑顶点。

| 适用年代 | 原始顶点数 | 备注 |
| --- | ---: | --- |
| 前602—公元11年 | 86 | 包含当前秦、汉代表年 |
| 11—1048年 | 71 | 包含唐755年 |
| 1048—1128年 | 146 | 可手动对比 |
| 1128—1368年 | 147 | 宋、元代表年采用此线 |
| 1368—1855年 | 100 | 明、清代表年采用此线 |

时间采用包含起年、不包含讫年规则。在共同边界年切换到下一期资料，这只是图集时期选择，不声称一次改道在该年瞬时完成。没有资料的年代不外推；1855年及以后保留现代参照。

这些线表达中下游大尺度流向，来源没有可核验的定位误差或比例尺。本版没有解决唐代逐年河岸、全部支流或湖岸的复原；放大后的历史线仍受图集原精度限制，线宽不是真实河宽。

## 显示替换与精细资料

历史河道加载成功后，删除现代概览黄河在112.4472°E以东替换区域的下游线，保留上游参照。裁剪只切断已有段，不跨越空缺连接。历史线与现代上游接边不代表已经复原衔接河段。

精细OSM资料中的现代黄河主线通过规范化名称全值匹配确定，“双河水库”“上黄河”“黄河故道”等名称不能据此作为主河。对于无名黄河水面，用已采集主线的真实顶点严格落在 `water=river` 面内的证据建立关联：33个水面、47条证据。切换历史河道时，仅在下游替换范围内遮蔽有证据的关联水面。每条关联都保存OSM身份、源点和核验依据；不会仅凭落在矩形内就隐藏其他水面。搜索结果与渲染使用相同替换规则，避免选到已被隐藏的现代下游。

六区域细节来自现代OSM，原始线坐标和水面边集合已核对保留。完成相应区域数据加载后才替换视野内概览水系；未加载或未覆盖地区继续显示概览。水面是来源所记录轮廓，河线是中心线。水库、水渠等现代对象在卡片中明确说明现代参照，不归入唐代。

现代细节分296个gzip包，按视野和8/10级门槛加载；单个地物还遵守各自8—12级显示门槛。浏览器同时支持静态服务自动解压及直接返回gzip文件两种情况，缓存只保留当前需要的包与最近12个额外包。

## 验证

自动测试覆盖原始快照哈希、五期几何原样保留、年代边界、不同流向、裁剪不跨空缺、上游保留、近似名称排除、无名水面的源点证据及现代模式恢复。浏览器验收使用唐代与1368—1855年的实线/虚线对比，以及1128年事件联动和清除恢复；详情始终区分历史图集河道与现代参考地形。
