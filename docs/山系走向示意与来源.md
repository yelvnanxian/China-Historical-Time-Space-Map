# 山系走向示意与来源

V0.7不再把山系、高原的概括命名面画成地图范围块。山系名称仍能选择；只有选中且适合推导方向的山系，才显示一条或数段**走向示意，非测绘山脊线**。高原和海域不生成山系方向线。

## 交付与合同

- `public/data/mountain-directions.geojson`：51条Feature，几何仅LineString/MultiLineString。`groupId`与原`physical-interactive.geojson`一致；`labelCoordinates`位于最长保留线段的中段，可供名称排版；`bounds`为输出线包围盒。
- `public/data/mountain-directions-sources.json`：固定来源、输入/输出哈希、方法参数、运行库版本，以及全部52个候选的`availability`（`available`或`label-only`及原因）。
- `shared/mountain-directions.ts`：独立前端合同。主要属性还包括`name`、`geometryNote`、`method`、`sourceUrl`、`sourcePolygonId`、`sourceFeatureIndices`、`schematic:true`和`minZoom`。
- `data/evidence/physical-geography/mountain-directions-validation.json`：逐山系投影、面积、方向显著性、截面数量、保留/跳过分量、线长、线越界与定位点检查结果。
- `data/evidence/physical-geography/mountain-directions-overview.png`：内部QA总览，灰色原面只用于对照，橙色示意线和蓝色名称定位点。原面不因此回到产品地图。

## 来源与实际含义

原始几何来自Natural Earth `ne_10m_geography_regions_polys` 5.0.0，固定提交`ca96624a56bd078437bca8184e78163e5039ad19`，完整快照及SHA256沿用现有自然地理证据。比例尺为**1:10,000,000，不是10米分辨率**。本次不修改原始快照、`physical-regions.geojson`、`physical-interactive.geojson`或其他河湖源文件。

源多边形是制图者给山系名称的概括范围。本次推导仅描述这种范围的几何主方向：没有从高程数据提取真实山脊，没有野外测量、地貌分界判读或历史山体复原。即使曲线看起来平滑，也不提高源资料精度；它不能用于路线导航、精确山脊或山体边界判断。

## 可复现方法

1. 只选现有52个`kind=mountain`对象。每个独立Polygon分量分别投影到以本山系为中心的局部方位等距米制坐标，不连接不同分量。
2. 在分量内取64×64规则面积采样，计算几何主方向。面积小于25平方公里、相对最大分量小于0.1%、主轴尺度不足20公里，或主次轴标准差比小于1.35的分量不生成线；阈值仅用于本比例尺的可读性，不是山系是否存在的判断。
3. 沿主方向取16–64个垂直截面，目标间距20公里，两端各留2.5%。每个截面取最长内部交段的中点，形成一个主要走向。截面中点发生过大横向跳跃时分段，避免为了连续而强加陡转连接。它不覆盖所有支脉。
4. 对开放折线做两次Chaikin平滑，再裁回自己的源分量，去掉短于10公里的碎段；覆盖主轴不足40%或异常曲折的结果不发布。
5. 转回WGS84后再次裁到原始经纬度多边形，消除投影直线段差异造成的轻微越界。保留分开的线段，不跨空白补连接线。名称点取实际输出最长连续线的经纬度平面长度中点，确保落在线上。

这些参数是统一的显示推导规则，没有按某山系手写经纬度或人工描线。输出有截断或间隔，不表示山体真实断开；只表示示意方法没有在该处给出连续线。

## 覆盖结果与降级

52个候选中51个有示意线，南高止山脉因源范围接近团块、单一主方向不明显，保持名称展示。天山包含两个源分量，极小分量不满足可读性阈值，主分量正常输出；没有把小分量与主分量跨空白相连。它们在来源清单与验证报告中分别记录。

源数据本身没有横断山、长白山的独立命名面，本次也没有给这些对象补造线。前端没有找到某组方向Feature时，保留原名称和DEM，并明确仅名称展示，不能自动退回山系填色或轮廓。

## 重建与验证

需要Shapely 2.x、pyproj 3.x与NumPy，重建无需网络：

```sh
python scripts/build-mountain-directions.py
npx tsx --test server/mountain-directions.test.ts
```

可选QA总览需要Pillow：

```sh
python scripts/preview-mountain-directions.py
```

生成脚本检查完整连续线不在源范围之外、名称点在线上，并记录原文件哈希。独立测试进一步检查所有候选状态、来源关联、无高原/海域误导线、线不闭合为轮廓、每段仅位于单个源面分量、名称点与线一致、原面与输出的校验值一致。形状总览用于查看显著折返或跨区连接；这些检查验证推导和展示合同，不把几何合理性包装成山脊地理真实性。
