三国补长安、洛阳、蓟、钱唐、番禺、广陵、江陵、晋阳、平城、临淄、敦煌。内容涉及五都与宫城、蓟城水利、广陵临江观兵、江陵解围、广州分置、钱唐封爵、仓慈治理与商旅通行。平城仅有地区部族活动概述，未确定230年县城归属；钱唐封爵不表示封侯者赴任或当年置县。

晋补长安、洛阳、蓟、浚仪、钱唐、广州、广陵、襄阳、晋阳、平城、临淄、邯郸、潼关、敦煌。13个节点包括311年洛阳失守、313年长安即位、316年长安出降、282及313年南京地区改名、317称晋王／318称帝、306大成／347成汉灭、378襄阳被围／379失守，以及417年潼关和长安史事。317年节点关联既有事件`eastern-jin`，不改旧事件。

三国的浚仪、邯郸、潼关仍缺本期专门档案。现有资料不足以核定本期事实，不能将汉末记录、邺城故事或西晋太康县目硬套为230年城市档案；这些地点的原入口与已有历代资料保留。

新增15组原始API、文本及元数据快照，三国使用12个来源、晋使用13个来源（部分复用已归档资料）。本轮101条引文按实际引用计数，不代表101种独立史料。项目累计261份档案、622个纪年，唐104、宋51、明28、元8、清9、秦8、汉16份档案保持原值。

## 年代、名称与来源

三国页面范围220—280年，默认230年；两晋页面范围266—420年，默认280年。二者年代重叠并不意味着266年后的魏仍然存在，也不意味着两晋页面中的所有城池都受晋朝统治。档案中的魏蜀吴、西晋、东晋及同期其他政权分别说明。

本轮结合固定修订的古籍电子转录与百科概述。新引文保留原始API、文本、修订号及SHA-256，展示采用简体，原文不改字形。引文可回查不等于已完成刻本校勘、考古或古城空间考证。郡县列表不按列序推治所，郡国户口不作城市人口，太康时期县目也不用于倒推230年。

三国广州地区的目录入口改用“番禺”，可继续通过今名广州检索。依据现有固定快照的三国番禺记载，只修正阅读入口称谓，不推断230年的具体州治或辖境。建业、建邺与建康的分期、司马睿称晋王与称帝等，按原文的事件及年份分别呈现。

## 构建与数据保留

```sh
python3 scripts/build-reading-content.py
npm test
npm run build
```

统一入口在既有各批之后合并三国、两晋，最终核验所有引文与来源哈希。两个独立构建器支持`--check`只读核验；新增纪年分别使用`sanguo-timeline-`和`jin-timeline-`前缀，使重叠年份能依据记录进入对应时期。

与V0.20逐项比较，原236份档案、600个纪年、全部旧来源和8条历史地理均保留。核验及番禺更名引文见`data/evidence/reading-content-v021-preservation.json`。目录本轮仅调整版本、数据说明与三国番禺称谓；不以文字补画古城、行政界、山脉或河道。版本与目录更名所影响的派生哈希按依赖重建。

## 验证结果

- 完整测试272项通过，TypeScript与生产构建通过。最初校验发现两条年号摘录缺少上下文，已扩为对应人物、事件的完整原句后重新全量通过。
- 新增引文可逐字匹配固定修订文本；原始API、确定性转录转换与SHA-256核验通过。两批独立重复合并后，发布文件字节哈希不变，无新增重复节点。
- 逐项核对旧236份档案、600个纪年和全部旧来源保持一致；番禺是唯一目录地点名称调整，坐标与时期关系未改。派生行政关联、诊断与自然覆盖报告只有依赖哈希变化。
- 浏览器显示三国14份、晋17份“本朝名城”。输入今名广州可找到三国番禺，展开《三国志》出处并点击264年复置广州节点后，URL与年份导航同步。
- 从三国建业的历代大事记点击317年称晋王，切到晋时期并保持南京地区；282、313改名与317、318称王称帝分别列示。晋朝检索潼关可读《宋书》纪年出处，点击节点切到417年并保留潼关。
- 浏览器未记录error/warn，沿用已有档案、检索与年份控件。
