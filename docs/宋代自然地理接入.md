# 宋代自然地理接入

宋代地图现在按唐、明的同一加载规则接入现代河湖、山峰、山脊及DEM近览。唐代755年历史治所仍仅用于唐代；宋1200年黄河下游采用已有1128—1368年历史几何，隐藏现代下游线及有证据关联的水面，其他河湖仍标为现代参照。

## 覆盖与限制

`data/evidence/song-natural-coverage.json` 对现有29个宋代名城入口逐一核查，29个坐标都落在已取得真实OSM响应的采集窗口内。此结果仅表示查询覆盖，不保证支流、小湖和山峰完整，也不能用采集框充当历史辖区。

宋地图可按视野和缩放复用40个现代采集区，发布包合计131,288个水面、21,987段河流、26,396段溪流、35,878段运河及水渠、8,407个山峰、147个山口；数量为对象/分段数，不是独立河流条数。8级加载主要河湖，10级加载局部支流和峰点，12级显示更小水面。OSM名称未收录时不编造名称。

山脊专门数据仍为5个采集区的14,330条山脊、刃脊、陡崖与命名峰点，尚非全国覆盖。本轮补充的是五个真实DEM近览，不能声称同时补全全国山脊。

五窗共新增6,467条等高线；全部22窗共18,451条。每窗使用3×3张Terrarium z11原始瓦片，等高距50米、主线250米。原17区所有元数据和文件哈希保持不变。新峰坐标的DEM取样与已有OSM峰高标签在同一数量级；两者不是同一测量，不以标签修补DEM，不把石鼓脑的格网取样写成实测峰高。

新增窗口地面像素约65—69米，放大不会获得新的源分辨率。负高程只在本陆地山形层中透明，不补平、不判定真实海拔；`landformDisplayMask`保留未显示样本的游程掩膜、数量、原始高程范围及SHA-256，可复核每一处省略。

## 前端行为

- 等高线9级加载，9.5级显示全部细线；城市近览默认9.5级。
- “地图工具→山地近览”可搜索杭州、南京、福州、泉州、南昌并跳转到11级。两处“北高峰”加所在地标签，源名称不改写。
- 点选城池时，山川与河湖形状保留，名称和点击关闭；点选山川/河流/全部遵守各自交互范围。
- 状态明确为“已加载数据含多少条线（部分在视野外）”，不把整包线数误称视野可见数；无近览不说明当地没有山。

## 重现与核验

```sh
python3 scripts/audit-song-natural-coverage.py
/tmp/map-chgis-runtime/bin/python scripts/build-mountain-shapes.py --offline
/tmp/map-chgis-runtime/bin/python scripts/validate-mountain-shapes.py
npx tsx --test server/song-natural-detail.test.ts server/tang-detail-display.test.ts server/mountain-shapes.test.ts
```

Python构建依赖numpy、pillow、contourpy；路径可替换为安装相同依赖的环境。宋代覆盖审计核验每个已使用OSM来源的原始响应、查询语句和元数据哈希；DEM独立校验逐顶点反采样、不调用生成器，最大计算误差小于0.011米，该值不代表原始DEM测绘精度。

2026-09-27浏览器验收：临安、建康经名城入口定位到9.5级，分别加载1,367和658条低山等高线，截图确认西湖西南群山和紫金山周边线形可见。南京250米等高线可点开现代地形详情，正确显示50米等高距/250米主线与OSM峰点链接。临安切到“城池”后河湖、等高线形状保留，自然名称和海拔标签消失。泉州分享链接直接定位9.5级，加载1,625条等高线，可见清源山周边群山及晋江、洛阳江、九十九溪；已确认使用更新后的29入口API。独立验收标签与临时Vite进程测试后关闭。
