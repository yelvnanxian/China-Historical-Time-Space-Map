# V0.14 明代城市与建置史料

日期：2026-09-25。

## 本次交付

- 明代可选地点从19个扩展为28个，28处全部补齐本朝档案。新增的明代阅读入口是苏州、济南、兖州、武昌、福州、重庆、桂林、宁波、南昌；复用已有现代地区参考坐标，未宣称这是明代城址实测坐标。
- 城市档案与额外的凤阳府、淮安府、云南府、贵阳府组成32条研究；《明史》地理志卷40—46共7卷、76段逐字引文。来源为清代编纂正史的一条文献链，尚未全面完成同期方志与遗址互证。
- 65项研究纪年中，63项新增为独立节点，南京1368和大理1382合并到原有记录并补证据。南京与北京的1421年记录均澄清为迁都后的职能变化，不再声称1421才有南京称号。12项建国前沿革标明“建国前”，在历代模式可读。重庆原文仅为“洪武中”，没有添加虚假的确年节点。
- 29个具名原模型（26府、3县）按名称、源类型与隶属对应研究，点击城市档案的“相关建置与参考范围”可查看。原模型几何未改；现代点位及距离不参与身份推断。太原县、临淄县和邯郸县不会被当作上级府。
- 大事记默认显示历代，可切换本朝；筛选按时期起止年份，不把明代视为只有1582年。新史料卡片显示已核对事实、待考事项、逐字引文与固定版本链接。

## 重点纠正

| 项目 | 处理 |
| --- | --- |
| 太原 | 晋阳地区入口在明期标“太原县”，按原文解释平晋县迁治、更名；太原府治阳曲另行区分。 |
| 顺天府 | 保留1391模型原名，同时提示1403年才改称顺天府，1391年应读北平府。 |

| 贵阳 | 1582为贵阳府，1601才升军民府，新贵县1586才置。没有将1391“贵州府”强行配为贵阳。 |
| 潼关 | 分开关隘、守御千户所、卫及其军政隶属，暂不强配县/府范围。 |
| 扬州、凤阳 | 淮海—维扬—扬州属于建国前；临濠—中立—凤阳为府名变化，中都另属都城建置。 |
| 开封 | 正统十三年条支持河与城的相对位置变化，不据此声称城市迁移或重绘1448年精细河道。 |

## 重建

```sh
python3 scripts/research-ming-geography.py
python3 scripts/build-ming-content.py
python3 scripts/apply-ming-catalog.py
npx tsx scripts/build-ming-boundary-research.ts
```

脚本使用已保存的固定修订API，离线核对并生成数据；原始API和展开年号模板/维基链接后的文本分别保存哈希。研究文字不生成新的地理几何。

catalog更新后，另重建唐代关联与诊断文件中的输入哈希：`npx tsx scripts/build-tang-boundary-crosswalk.ts`、`python scripts/build-tang-county-diagnostics.py`（Python环境需有shapefile、shapely、pyproj）。此次唐代关联结果与诊断统计均未改变。

## 资料限制

1391年的Hartwell数据是近似模型，不是1582年实测县界或完整明代疆域；《明史》综合多个时期，所列州县数量不能全部回填到同一年。贵阳、潼关卫、宁夏卫保留未关联说明。此次补充主要是城市与建置史料，未新增明代县治时序点、精细历史河岸或山地复原。已有现代地理参照与历史黄河分期资料继续保留原有性质。
