# V0.7 验收记录

2026-09-24。用户与市场角色独立评估后，由项目经理确定修复范围，地图、前端和内容组并行实现；主线程统一集成和浏览器验收。评价与规划见 [reviews](reviews/V0.7修复规划.md)。两份评价是基于产品和代码的角色评议，没有假称真实访谈或市场调研。

## 本次完成

- 山系、高原、海域的命名范围面彻底退出地图渲染源，不保留透明命中面、悬停轮廓或选中面；原始数据保留作来源证据。
- 山系默认显示名称与DEM山影。点击名称或搜索结果后，51个可用山系显示开放的主走向示意；南高止山脉因主方向不明显，仅保留名称。方向由概括命名范围派生，不是测绘山脊或古代地貌复原。
- 同时显示时，画布区域只选历史行政区；山川通过名称/搜索结果选择。纯山川模式仍支持河线、湖面直接选择。城市、自然、行政高亮与详情互斥，行政详情在工具中优先呈现。
- 四步“使用帮助”：首次轻提示、跳过、重播、完成后本地记忆、Escape退出及焦点回到入口。主要模式按钮在小屏为40px高。
- 新增“本朝名城”与“本朝看点”：11期各3份，共33份，涉及17个既有地点；每份有来源与摘录，明确概览整个时期，不等同地图代表年的单日截面。
- 城池时间线从10城35节点扩至22城71节点；独立地点仍40个、目录事件仍34个。秦时期的开封入口改名浚仪，保留大梁别名和出处。覆盖及缺口见 [城市内容覆盖](V0.7城市内容覆盖.md)。
- 修正分享保存范围的文案、精选地点计数说明；自然模式复位返回中国及周边地区。独立复审发现山系数据错误未与全局地图错误隔离，已修复并增加回归检查。

## 自动验证

最终代码、数据和秦代名称调整后执行：

- `npm test`：58项全部通过。
- `npm run build`：TypeScript与Vite生产构建通过。
- `git diff --check`：本轮源码、配置与维护文档通过；网络来源快照保留原始格式。

新增检查包括：同时显示的选择政策、山系面从渲染源移除、可选图层错误隔离、走向线与名称点约束、原始与派生文件哈希、每期看点覆盖/可见性/引用、22城时间线与逐字摘录。来源吻合和程序验证不等同完成所有历史事实、古址或山脊的学术核定。

构建仍有既有MapLibre主包大于500kB的提示；本轮没有为此扩大到分包或矢量瓦片重构。

## 延后范围

仍有18个目录地点未建立独立时间线，各期只有3份专门看点；秦至隋行政面仍无已接入资料。统一搜索、完整视野分享、更多城池资料与精密山脊数据按规划后续推进。本版没有把缺失资料补画成确定疆界，也没有把33份时期看点宣传成33座新城市。
