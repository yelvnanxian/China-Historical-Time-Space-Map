# 唐代北方与西域城镇内容补充

本批交付 `data/tang-expansion/north-west.json`，提供 **50 份唐代档案、28 个既有入口、22 个新增地区入口、118 条原文摘录和 11 个来源**。它与南方、东部和连接地区的数据包合并使用，不单独改写总目录或前端发布文件。

幽州与范阳是既有的同城不同叙事入口，因此档案数量不能直接等同于互不重叠的古代城市数量。本批完成约定的北方、西域目标范围，不声称覆盖唐代全部州县。

## 内容覆盖

| 区域 | 档案数 | 新增入口 |
| --- | ---: | --- |
| 关中与两京 | 9 | 凤翔、同州、华州 |
| 河北与河东 | 14 | 蒲州、绛州、魏州 |
| 中原与山东 | 14 | 博州、齐州、兖州、青州、登州 |
| 河西与西域 | 13 | 凉州、甘州、肃州、瓜州、西州、伊州、庭州、龟兹、于阗、疏勒、焉耆 |

28 个既有入口为：长安、洛阳、幽州、范阳、晋阳、大同、临淄、邯郸、潼关、敦煌、马嵬、灵武、睢阳、相州、河阳、陕州、郑州、滑州、怀州、恒州、贝州、平原、鄜州、潞州、邓州、许州、徐州、开封。既有地图入口名由总目录维护，正文解释唐代身份。

每篇有独立摘要、地域分组、年代命名说明和至少两条逐字摘录。新增入口仅关联唐代。`name` 使用常见州城称谓，`nameByPeriod.tang` 使用地图代表年 755 年名称；全文则可讨论整个唐代，并明确变更年代。例如凤翔入口在 755 年显示扶风郡，瓜州显示晋昌郡。

## 证据与定位

历史建置主要来自实际取得的《旧唐书》卷 38、39、40 固定修订全文；战事与事件复用本项目已保存的《资治通鉴》卷 217、218、220、221、222 和《旧唐书》卷 10。绛州天宝改郡依据另补固定修订百科条目，明确为二手材料。来源元数据、全文、SHA256 及本批取得的原始 API 响应均保存在 `data/evidence/tang-expansion/north-west/`。

新增点的地理依据来自实际下载的 GeoNames `CN.zip`。`geonames-selection.json` 保存归档下载时间、整体 SHA256、22 条完整原始记录、原始经纬度和四舍五入到 0.01 度的显示坐标。GeoNames 采用 CC BY 4.0，数据中保留署名和来源链接。

这些坐标只是现代地区阅读入口。它们不确定唐代城址、县治、国都、镇城、城垣或街道；尤其西域城镇、古瓜州和多次迁治地点，不将现代点直接标成古址。古籍地理叙事与现代参考坐标分别提供证据。

已经特别区分：幽州与范阳县、华州与滑州、登州与邓州、许州与徐州、鄜州与福州、临淄县与齐州临淄郡、敦煌沙州与晋昌瓜州、安西与北庭。西州置州年份以及庭州、安西有关纪年的数字文本存在内部差异，正文保留必要说明，避免凭一条争议记载强定年份。

## 构建与复核

正常构建只读取保存的证据，不访问网络：

```sh
python3 scripts/build-tang-north-west.py
npx tsx --test server/tang-north-west.test.ts
```

三个测试覆盖：约定 28 旧入口和 22 新入口的完整性、字段和简体编辑文本；固定修订链接、全部快照哈希与 118 条逐字摘录；22 个现代点与 GeoNames 原始记录、坐标方向及 0.01 度显示精度。当前三项全部通过。摘要、名称和说明使用简体，来源标题、摘录和全文保持原始字形。

重新获取文本时可使用：

```sh
python3 scripts/fetch-tang-north-west.py
```

默认请求元数据中记录的修订号；只有显式传入 `--latest` 才查询最新修订。已用保存的四份原始 API 响应离线验证解析程序，可逐字重建当前四份文本快照。重新获取会更新获取时间，完成后须重建并重新测试数据包。旧有古籍材料由构建脚本从项目既存证据中复制，保留原始取得时间。

使用实际下载的 GeoNames 全包重新提取现代点：

```sh
python3 scripts/extract-tang-north-west-coordinates.py --archive /path/to/CN.zip
```

脚本按人工选择并保存在 `north-west-places.json` 的记录 ID 提取，要求传入原始下载包，其修改时间应仍为下载时间。全量归档不提交仓库；22 条原始记录与归档校验值已保存，足以复查本批使用的数据。换用新归档将更新坐标证据，需要重新构建和审阅。

这些自动检查证明来源可追溯、摘录和坐标处理一致，不替代版本校勘、历史地理研究或考古定位。本批没有新增精确疆界、城址几何、交通路线或未经审校的人口规模排名。
