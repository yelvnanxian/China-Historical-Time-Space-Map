# 自然地理图层说明

V0.3将河流从Natural Earth 1:50m升级到1:10m，并增加湖泊与自然地理名称。范围为东经70–142度、北纬10–56度，全部是现代背景。

## 交付

| 图层 | 文件 | 数量 |
|---|---|---:|
| 河流/湖内中心线 | `public/data/rivers.geojson` | 277 |
| 湖泊/部分现代水库 | `public/data/lakes.geojson` | 234 |
| 河流名称 | `public/data/physical-labels.geojson` | 32 |
| 湖泊名称 | 同上 | 20 |
| 山脉和山峰名称 | 同上 | 26 |
| 海域名称 | 同上 | 8 |

标签共86个，小于100个上限。涵盖长江、黄河、淮河、汉江、渭河，青海湖、鄱阳湖、洞庭湖、太湖，秦岭、太行山、天山、喜马拉雅山，以及珠穆朗玛峰等。名称按缩放级别逐步显示，减少同屏碰撞。

## 数据与派生方法

原始数据来自公开领域的Natural Earth，固定仓库提交 `ca96624a56bd078437bca8184e78163e5039ad19`；河流、湖泊、自然地理区域和山峰数据版本为5.0.0，海域为5.1.0。原始URL、实际下载时间、版本文件链接与哈希见 `public/data/natural-geography-sources.json`，可读列表见 `public/data/README.md`。

河流真实线和湖泊真实面裁剪到区域后分别用0.012度、0.006度容差进行保拓扑简化。原数据中有两条湖泊几何需先作有效性修复，来源要素索引与操作已记录。没有手绘补充河道或湖岸。

标签位置来自原始几何：河流取最长连续来源线的长度中点；湖泊、山脉和海域取来源面内代表点；山峰复制原始Point坐标。所有标签带来源数据集、要素索引及派生方法。对于山脉和海域，这只是制图名称的位置，不是疆界或精确地物边界。

NE的河流缺少中文属性，因此32个常见河名经本项目人工翻译，仅改变展示文字，标记为 `editorial-translation`，不改变几何。`nameEn`、`sourceName` 保留来源文字。中文湖泊、山脉和海名主要使用NE本身的 `name_zh`；有一条明显无关的水库译名被排除并留档，没有把上游译名一概视为已核验。

## 验证与使用边界

本次验证所有几何有效且在范围内，所有标签字段正确且不超过100个；86个标签坐标逐一回查来源几何，山峰原始点完全保留，其他派生点只允许六位小数舍入造成的微小误差。结果在 `public/data/natural-geography-validation.json`。

1:10m表示1:10,000,000制图尺度，不表示10米分辨率。经纬度小数位数也不表示米级测量精度。现代河湖、现代水库和现代海岸不能当成755年或其他历史时期的实况；本次没有构造森林、草地的历史分布。真实历史自然地理仍需另外选取时代明确、有许可证和研究依据的数据。
