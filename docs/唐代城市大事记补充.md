# 唐代城市大事记补充

本批把唐代档案中能落实到年份的建置、迁治、改名、战争和文化节点整理为大事记，合入现有城市时间线。原有跨朝记录继续显示，不因选择唐代而删除或覆盖。

## 覆盖

- 唐代完成清单104个入口全部有纪年节点，本批共346条；其中96个入口至少有三个不同年份。
- 原有22城71条跨朝记录逐项保留。3条已存在的安史事件按原ID去重后，全库为106个城市入口、414条大事记，净增343条。
- 幽州和范阳属于同一城市地区的不同叙事入口，104不是104座互不重复的古城。兴庆府、上都等既有跨朝入口仍保留。
- 本批主要补足州府建置与城市沿革。苏州山塘街、明州迁治筑城、桂州相思埭、安南大罗城、南诏迁都与苍山会盟等有明确纪年的节点也已加入。

## 来源与时间处理

来源复用已实际保存的《旧唐书》卷38—41、《资治通鉴》相关卷及现有城市百科固定修订快照。每条大事记保留来源ID、逐字引文和说明；发布来源包含原始快照路径、抓取时间、固定修订链接及SHA-256。显示文本转为简体，证据原文不改。

行政建置的选取明确指定卷、州府条目和原文日期，不在全卷中按重复的“天宝元年”“乾元元年”猜配。省略年号的“三年”“七年”等，引用保留其前文年号语境；排序年份只作年号换算，不把传统月、日直接冒充公历日期。

已专门处理的风险包括：

- 高宗上元二年为675年，肃宗上元二年为761年。温州、于阗与襄州、江宁分别使用正确的年号。
- 临淄县只采用青州辖县关系，没有把齐州曾用的“临淄郡”更名节点贴到临淄县城。
- 郑州迁治管城取贞观七年633年；柳州改名取承接贞观纪年的八年634年。
- 所读《旧唐书》西州条“贞观十三年”与安西府条“贞观十四年”存在异文，设置西州采用后者640年的明确记载，并在摘要解释取舍。
- 北庭陷落年代的源条目存在矛盾，没有据单条古籍强定陷落时间；剑州改普安郡的年份也未采用有疑点的异文，而保留699年剑门县、713年剑州名称及758年恢复州名等节点。
- “安史之乱”这种跨地区、跨年的总览事件不按总览起年复制到所有关联城市；复用的是已有详细事件，避免让潼关失守错排到755年。灵武即位等同一事件也不重复列入。

## 重建与验证

```sh
python3 scripts/build-historical-context.py
npx tsx --test server/historical-context.test.ts server/tang-timelines.test.ts
npm test
```

主构建自动调用`build-tang-timelines.py`，从明确的编辑选择和已存快照重建`data/tang-city-timelines.json`，再合入`public/data/historical-context.json`。`data/tang-timeline-selections.json`保存迁治、文化、西域及承接年号的单独选条。

`legacy-baseline.json`保留本次补充前22城71条原始记录，用于逐项检验不丢失、不改写。全量测试同时检查104入口覆盖、96入口不同年份数量、全部引文的原文与哈希、固定修订链接、已有事件去重和上述错年错城风险。时间线重建不联网；数据内容可确定性复现，主文件的`generatedAt`和验证报告生成时间随重建更新。

未修改目录、地点坐标、共享类型或前端交互。历史地理故事仍使用原构建的8条数据，本批没有添加未经核定的古河道几何。
