# V0.13 县级史料核查记录

本版针对唐城县、湖北吉阳县、海南吉阳县以及上一版点面诊断中的存疑县，补查固定版本的《旧唐书》《新唐书》《元和郡县图志》《宋史》和 CHGIS V6 官方数据字典。研究包保存于 `data/evidence/tang-county-research/`，每条事实都附原文、篇卷定位、版本链接和快照 SHA256。

## 三个重点案例

- **唐城县**：CHGIS 738—912 的有效记录、两唐书“开元二十六年分枣阳置”和《元和郡县图志》本版“开元二十四年宋鼎奏置”并列保留。736/738 可能是不同记事口径或版本异文，尚未擅自择一；随后记录从913年开始，不能把912直接称作事件年。
- **湖北吉阳县**：旧唐书和元和志支持梁平阳、后魏京池、隋大业二年（606）改吉阳；新唐书记元和三年（808）省入应山后复置；宋史只给“开宝中废吉阳”的时段。CHGIS 969是最后有效年，不等同于废县事件年。
- **海南吉阳县**：两唐书支持贞观二年（628）析延德置，宋史记熙宁六年（1073）废为藤桥镇。CHGIS 数据字典规定 `end_year` 是撤销或改名之前的最后有效年，所以1072与1073相容，不再显示为一年冲突；后续吉阳记录在1136年重新开始。

## 研究规则

1. 史料先用于单位身份、上级州郡、建置沿革和年代核对；文献中的里程只作为相对方位，不换算成现代经纬度。
2. 只有古籍州属、名称沿革和原始类型共同支持的异地同名候选，才从当前模型候选中排除。现代地点或距离单独不足以否定对应关系。
3. 跨年改名链只作为候选关联，保留原始点和原始模型，不代表历史县界已经确认。阴盘—潘原等矛盾来源继续标为待核。
4. UI 将研究分为“已核对事实”和“仍待考证”，逐字引文收在展开区；史料补充不改变县界几何。
