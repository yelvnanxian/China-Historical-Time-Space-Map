# V0.10 唐代地图交互与精细地理验收

日期：2026-09-25。接续V0.9，范围为唐代地图；数据缺口保留，不以现代地区或示意线补造唐代事实。

## 本轮结果

1. **郡与辖区**：解释742年改州为郡、758年复州；755年郡按府州级展示。本版本1,243个跨年治所映射ID（755年实际1,007个已关联点，另236个辅助ID）、91个精选入口关联741年参考州级面，含212条明确改名链；无依据的13个精选入口不强配。治所点选静默高亮，详情可定位完整辖区。修正许州/徐州同源名称对调，原名及证据保留。处理关联表晚到、旧请求在地图加载后复活、切期误消费上期几何等时序问题。
2. **放大水系**：现代地理扩至32个采集区、213,897个要素、460个gzip包；新增35,525个要素，原六区296包字节与元数据不变。补入15个西部区域、11处主要城池近景。只有同名且实际加载的精细河段可以替换对应概览线，未取得替代数据的河流继续保留。
3. **山地线与峰点**：五个采集地区、22个查询框全部取得来源；14,330个对象，包括8,940条山脊、54条刃脊、1,746条陡崖、3,590个命名峰点。保留完整OSM way顶点，没有峰点连线、平滑或补造主脊。与唐细节层重复的194个峰点去重，搜索归口；已选峰用独立高亮源，加载新包不会丢失选择。
4. **点选筛选**：城池、山川、河流、全部只影响名称及可点击对象，基础地物保留。全部模式由同一命中仲裁决定目标，河湖与山脊优先于行政面；城市模式可点击因文字避让而没有标签的治所圆点。自然详情、行政详情与城市档案互斥。
5. **自动层级**：去除手动层级选项。搜索和辖区定位后仍自动分级；选中范围独立保留，不因当前背景层级变化而消失。
6. **来源状态与中文**：封闭、涵洞、隧洞及地下水道用灰色虚线，有覆盖不推断一定在地下；间歇/季节性水面采用浅色和虚线岸线，选择高亮也保留状态区别。修复4段仅有繁体标签的河名及“虎头山”，保留原标签和原包。无中文依据不猜译。

## 浏览器实际检查

使用应用内浏览器，桌面1280×720和手机390×844：

- 长安“查看京兆府辖区”定位并持续高亮参考范围，缩放后县级背景仍自动显示。
- 唐细节搜索“吴郡”，打开755年治所记录，显示742—757存续年、对应苏州及741年范围说明。
- 苏州水系在河流模式保留城池基础点和地理形状，隐藏城池标签；全部模式直接点击湖面打开水体详情，没有被县域面截走。缩放至14级仍能加载细节。
- 秦岭“南羊山大脊”搜索后显示来源way、线长及完整走向。关闭详情后直接点击无文字覆盖的山脊线，再次打开同一资料；切城池模式后山脊线和峰点保留、自然名称隐藏。
- 敦煌与党河绿洲入口在9级显示党河、水库、鸣沙山等资料；治所定位放大至10.5级后显示党河、月牙泉和细节水道。未有可信辖区关联的敦煌县明确提示缺口。
- 正式服务中进入天山地区，按名称找到腾格里山脊并打开OSM way/1117252023来源详情；本次3001页面无浏览器控制台错误。
- 手机四类按钮均在屏幕内，页面scrollWidth与clientWidth均为390；第二步引导清楚说明筛选只影响名称和点击，可关闭继续使用。

## 保留的限制

741年Hartwell面是近似行政模型，不是已核实的755年准确疆界；仍缺完整唐国界。CHGIS755原始治所点在西域远西区域有覆盖缺口，未据现代聚落补造古代治所。现代OSM河湖、山地与高程仅作参照，无法据此断言唐代水道、湖岸或山体形态。黄河已接五期历史图集线，仍只表示流向而非逐年河岸。32个水系采集区和五个山地区域均有来源覆盖缺口，不代表全部唐域已达到同一精度。
