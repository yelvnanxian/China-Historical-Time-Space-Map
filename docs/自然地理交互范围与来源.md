# 自然地理交互范围与来源

这批数据让河流、湖泊、山系、高原和海域都可以被点选、统一高亮和按名字检索。它提供现代自然地理背景，不随历史年份变化，也不表示已复原某一朝代的河道、湖岸或海岸。

## 交付文件

| 文件 | 用途 |
| --- | --- |
| `public/data/physical-interactive.geojson` | 统一交互集合：277条河线、234个湖面、52个山系范围、10个高原范围、8个海域范围，共581条记录。 |
| `public/data/physical-regions.geojson` | 同一集合中的62个山系/高原多边形，便于单独使用。 |
| `public/data/physical-interactions.json` | 540个检索分组，包含名称、别名、组成图形ID、定位点和包围盒。 |
| `public/data/physical-geography-sources.json` | 固定来源地址、取得时间、SHA256、选择方式、几何处理方法和覆盖限制。 |
| `shared/physical-geography.ts` | 前端数据类型合同。 |

每个Feature的顶层`id`与`properties.id`相同。`groupId`连接应一并高亮的河段；`name`为简体展示名；`sourceName`保留来源原文；`sourceFeatureIndices`指向固定版本源文件中的记录位置；`sourceId`保留上游标识。`bounds`顺序为`[west,south,east,north]`，`labelCoordinates`顺序为`[longitude,latitude]`。

## 实际来源与精度

来源为公共领域数据Natural Earth，仓库固定到提交`ca96624a56bd078437bca8184e78163e5039ad19`。其中`ne_10m_geography_regions_polys`为5.0.0版，`ne_10m_geography_marine_polys`为5.1.0版。`10m`指**1:10,000,000（1:1000万）比例尺，绝非10米精度**。完整原文件保存在`data/evidence/physical-geography/`，可用来源清单中的SHA256复查。

山系与高原直接选择源文件里类型为`Range/mtn`或`Plateau`、与`[70,10,142,56]`窗口相交的所有记录。**保留这些记录的原始完整Polygon/MultiPolygon坐标**，未裁剪、简化、重画、缓冲或取凸包；记录可能延伸到选择窗口之外。海域使用既有8个海域标签对应的原始完整多边形。

这些山系、高原、海域多边形是来源制作的**地图概括命名范围**，不是山脊逐点测绘边界、精确山体轮廓或海洋法界线。山系和高原相互重叠符合这种数据用途。小比例尺数据放大后也不会获得更高测量精度。源没有横断山、长白山的独立命名多边形，本批未用猜测范围补齐。

河流、湖泊逐条复制现有`rivers.geojson`和`lakes.geojson`的几何，两个输入文件未修改。既有河线已裁剪到展示窗口并按0.012°简化，湖面按0.006°简化；原有两处湖面几何修复仍见`natural-geography-sources.json`。河线包含穿湖中心线，部分湖面为现代水库，不能据此判断古代是否存在。

## 分组、名称和定位

河流首先按Natural Earth的`sourceId`组合河段和穿湖中心线。既有`physical-labels.geojson`中明确列出的原始记录关联进一步组合长江的两条记录和黄河的三条记录。未仅凭同名或近似英文拼写合并，四川岷江与福建闽江保持独立。黑龙江的英文境外河段等未在既有审校表明确关联的对象也不擅自扩大分组。

主要河流复用既有按源记录索引审校的中文翻译；山系和高原优先使用源`NAME_ZH`，并用OpenCC转换为简体。仅补充缺失的“博罗科努山”，以及把源“萨彦岭”进一步区分为“东萨彦岭”；这些均标为编辑翻译，原文保留。其他非中文河名保留原名，空名和纯数字名明确显示“未命名河流/湖泊（源编号…）”，没有猜配中文地名。

每个Feature的定位点从该Feature实际几何计算：线取最长连续部分按经纬度平面长度计算的中点；面取内部代表点，避免凹面、岛屿孔洞导致中心点落在面外。检索分组可复用既有审校标签定位点。点用于地图定位与排版，不是地理测量中心或新测量坐标。

## 重建与验证

在安装Shapely 2.x和项目Node依赖后运行：

```sh
python scripts/build-physical-interactions.py --cache-dir /tmp/map-naturalearth-inputs
npx tsx --test server/physical-geography.test.ts
```

构建优先使用证据目录和缓存中的固定源文件，缺失时才下载；每次读取都核对预期SHA256。测试检查几何与原始记录完全相同、原河湖文件未变、各定位点位于实际图形、简体名称与唯一ID、全部图形被检索分组覆盖，以及长江/黄河多段联动与岷江/闽江区分。
