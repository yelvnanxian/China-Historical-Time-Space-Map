# 行政层级导航与资料核查标注

本次接入两种功能：行政区域详情中的上级、祖级和下辖导航，以及地图工具中的资料核查标注开关。

## 行政层级关系

关系来自来源面属性 `sourceHierarchy`，只连接同来源、同年份且政权与省路道字段完整一致的记录，不按地图空间包含、最近多边形或去掉行政后缀后的同名猜测。

- 县记录可同时跳转明确的府州级记录和道、路、省级记录。
- 府州级记录可列出来源路径下辖县；明确写出的府与属州两个字段保持区分。下辖列表包含来源明确的属州路径，不能把列表理解成全部直属县。
- 同一级出现多个相同完整路径的候选时，展示歧义与来源编号，不选取其中一面，也不向某一重复面归并下辖县。
- 各路径的唯一性独立判断：一个唯一道面仍可跳转，同时显示府州候选歧义。
- 国界完整范围并不在这些字段中，不将独立诸部或周边政权当成上级国界。
- 1820、1911年的CHGIS面未提供这些层级字段；1290年省面缺政权字段。这些保持缺项，不强行补齐关系。

CHGIS时序治所点的原始DBF没有上级行政区字段。点位详情明确说明这一限制；755年已有核查可跳到741年参考模型后继续浏览模型层级。既有唐、宋城池与模型关联仍保留其核定年份。

## 资料核查标注

地图工具的“显示资料可靠性标注”同时改变行政区模型和同期治所点的颜色。图例直接显示在地图左下角，可折叠，关闭工具面板后仍保留。

四类颜色表达核查程度，不是可靠性分数：

- **已核对**：存在明确的点面相容诊断或已核查的来源关联。仅此具体事项已核对，不表示古址或边线已经考定。
- **存疑**：点在相关面外、关联候选不唯一，或时序记录端点使用宽泛定年。详情显示触发原因。
- **缺关联**：现有核查明确缺少对应模型，或者来源名称未提供/未定名。
- **未核查**：有来源数据但没有上述核查。没有冲突标记不等于可靠。

唐755年点位使用现有741模型核查，严格不套用其他浏览年份；宋1200年的点面记录同样只用于1200年。记录不在本年出现或地图某地空白，不推断其历史上不存在。核查资料加载失败也不会被标为已核对。

## 边界状态复审

复审修复了三处状态表述：行政边界关闭、资料加载中/失败或年份没有面资料时，地图图例现在明确说明实际状态；治所包加载成功前不显示四类零值统计；同一记录同时存在点面核对与未定名缺口时，缺口优先显示，明确冲突优先于已核对结果。缺失的定年状态字段保持未核查，不因此推断年代可靠或存疑。

点选模式切换会保留行政面与治所原点的颜色参照，隐藏不允许点选的名称、选中状态与命中层。这与项目“点选仅改变交互对象，地理形状保留”的规则一致。年份切换重算时序点分类；755与1200的既有核查均不带到其他年份。关闭整个地图工具面板不会隐藏颜色说明，说明本身可折叠。

专项验证目前共9项通过（层级4项、核查标注5项），TypeScript及差异格式检查通过。
