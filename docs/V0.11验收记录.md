# V0.11 郡辖区与山地形态验收

日期：2026-09-25。范围：唐代江陵郡及同类关联排查、山地近览；没有补造新的历史边界或山脊。

## 郡与辖区

- 唐代郡、州、府在地图中属于县之上的同一层；742年改州为郡、758年复称州。道按监察分区说明，不等同现代省。
- 江陵郡原来只显示治所点，根因是741年CHGIS点名“荆州”与Hartwell模型名“江陵府”错期。按原始未舍入坐标、连续年代、明确更名字段与唯一性核验连续名称链，现关联模型94。来源中江陵府始于760年；界面仍注明741年参考模型，不能解释为755年正式府名或精确疆界。
- 同规则补齐17个755年郡治，当前317个府州层治所有232个关联、85个保留具体缺口。其中真正的郡260个，214个已关联、46个未关联。全部755年治所1,682个中1,024个关联，另有245个辅助跨年ID；不混用跨年总数与当前地图覆盖率。
- 全部缺口已逐项审计。没有具名模型、同名但点在面外等情况不自动强配；详情显示原因。
- 选已关联府州治所自动框出完整参考辖区，保留治所详情；反复点选仍有高亮，城池与全部之间切换不重新调整视野。关闭行政边界只隐藏图形，开启可恢复选择。

详见[唐代郡州辖区关联](唐代郡州辖区关联.md)，逐项数据见`data/evidence/tang-detail/boundary-crosswalk-audit.json`。

## 山地形态

- 新增17处源峰周边近览入口，覆盖秦岭、太行、祁连、天山、川西的部分地点。153张原始Mapzen/Terrarium z11高程瓦片生成11,984条等高线，共2,573,919个顶点，地面像素约55—67米。
- 9级起显示主等高线，10.5级起显示细线；透明山影表达坡向、坡度，线标签和线段可点选查高程与来源。没有用取数矩形或包围多边形表示山体边界。
- 峰点低于10.5级选中后近览到11级，保留精确源坐标。已有真实OSM山脊独立展示；详情只列10千米内最多三条已加载真实近邻，不把近邻关系当成同一山系。
- “地图工具→山地近览·看山形”可搜索与选择17处近览。四种点选模式均保留山影和等高线，只有山川/全部模式显示名称与接受山地点击。
- 高程为现代参照，不能称为唐代地貌复原；等高线不是山脊或山脉边界。原始DEM中12个可疑负高程像素保留归档，对应派生位置留空，未插值补造。
- 按当前视野加载等高线包，最多两个并发；图片失败后“重试”会移除失败源并重新请求。

详见[山地等高线与精细山影](山地等高线与精细山影.md)。近览只有已列17处，尚未覆盖所有山系。
