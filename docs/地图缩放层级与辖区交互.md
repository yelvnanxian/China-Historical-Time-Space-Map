# 地图缩放层级与辖区交互

本轮以唐朝为优先，保留既有历史边界名称、原始几何、来源年份和古今对照。城池点与行政区面分开管理；县域图层不代表已核定的唐代县城遗址。

## 层级规则

| 模式 / 缩放 | 行政区显示 | 城池点 |
| --- | --- | --- |
| 自动，zoom < 4 | 国家；唐资料缺主国界时，以省道为主、已有周边诸部为背景 | 隐藏 |
| 自动，4 ≤ zoom < 5.4 | 省 / 道 | 隐藏 |
| 自动，5.4 ≤ zoom < 6.6 | 府 / 州 / 郡 | 父地图按重要性显示主要城池 |
| 自动，zoom ≥ 6.6 | 县域 | 父地图显示已收录城池 |

行政背景始终随缩放切换，不提供手动固定层级。在资料缺失某个层级时优先退回更粗的已有层级。切换只影响渲染与交互，不修改原始数据。

唐朝当前接入 Hartwell 741 年近似模型，与地图代表年 755 不同。国家层只有 3 条周边独立政权 / 诸部记录，未提供唐朝完整国界。不能把十个省道范围合并成唐国界。全国视野使用省道与周边记录提供已知范围参考，并提供原图入口。

## 点选与搜索

- 每个可见行政名称是原生按钮，支持鼠标和键盘，选中时有按下语义、描边和底色。
- 地图表面只查询当前显示的行政层；全国唐朝视野中先选省道，未命中省道时才选已有诸部背景。隐藏的县面不会抢先命中。
- 选中区域以深色 3.5 像素边线和 0.3 不透明度底色高亮原始辖区几何，不生成包围盒或替代范围。
- 地图直接点选不自动改变视野。缩放切换到别的层级时，选中面保持独立高亮，背景行政层继续自动变化。
- 行政区搜索可查当前资料的所有层级。选结果后定位整个原始几何，并独立高亮选中面，不改变自动缩放规则。
- 行政区搜索结果消失后，焦点返回搜索输入框；地图标签重绘时保留仍可见标签的键盘焦点。
- 行政轮廓在各交互模式保持自动缩放显示；只有城池/全部模式生成行政名称并接受行政区域点选。在全部模式，自然对象优先于行政面，由共享命中仲裁确保只选一个对象。

## 父地图接口

`shared/map-detail-levels.ts` 导出 `MapViewLevel`、`resolveMapDetailLevel`、`mapDetailZoomThresholds`。

```ts
resolveMapDetailLevel(
  viewLevel: MapViewLevel,
  zoom: number,
  availableLevels?: readonly BoundaryLevel[],
  options?: { primaryCountryCoverage?: boolean },
)
// requestedLevel, activeLevel, visibleLevels, interactiveLevels,
// showCities, isFallback
```

`HistoricalBoundaryLayer` 始终以auto解析实际资料与缩放。`interactionMode`控制行政文字和点选；`selectionRequest`支持外部按boundary id选中，`focus:false`不移动视野、`quiet:true`保留当前城市或治所详情。原图打开由父组件通过`onOpenAtlas`调用现有原图查看器。郡州关联的来源规则和数据接口见[唐代郡州辖区关联](./唐代郡州辖区关联.md)。

## 验证

`server/map-detail-levels.test.ts` 覆盖缩放阈值、低缩放县面不可命中、唐国家范围缺失的降级策略和资料缺层处理。`server/tang-boundary-crosswalk.test.ts` 检查郡州关系的原始点、年代、明确更名字段及子县隶属。旧解析器仍保留兼容的手动值，但地图组件与界面不再使用固定层级；浏览器验收重点检查搜索或城池联动后继续缩放仍保持背景自动切换。
