# 地图缩放层级与辖区交互

本轮以唐朝为优先，保留既有历史边界名称、原始几何、来源年份和古今对照。城池点与行政区面分开管理；县域图层不代表已核定的唐代县城遗址。

## 层级规则

| 模式 / 缩放 | 行政区显示 | 城池点 |
| --- | --- | --- |
| 自动，zoom < 4 | 国家；唐资料缺主国界时，以省道为主、已有周边诸部为背景 | 隐藏 |
| 自动，4 ≤ zoom < 5.4 | 省 / 道 | 隐藏 |
| 自动，5.4 ≤ zoom < 6.6 | 府 / 州 | 父地图按重要性显示主要城池 |
| 自动，zoom ≥ 6.6 | 县域 | 父地图显示已收录城池 |
| 只看国家 / 诸部 | 仅已有国家层记录 | 隐藏 |
| 只看省 / 道 | 仅省道层 | 隐藏 |
| 只看府 / 州 | 仅府州层 | 隐藏 |
| 县域与城池 | 县域层 | 显示 |
| 只看城池 | 不画行政区面和线，不提供行政面点击 | 显示 |

自动模式在资料缺失某个层级时优先退回更粗的已有层级；手动模式不偷偷切换到其他层级，而显示缺失提示。切换只影响渲染与交互，不修改原始数据。

唐朝当前接入 Hartwell 741 年近似模型，与地图代表年 755 不同。国家层只有 3 条周边独立政权 / 诸部记录，未提供唐朝完整国界。不能把十个省道范围合并成唐国界。全国自动视野使用省道与周边记录提供已知范围参考；手动国家模式只展示真实已接入国家层，同时提供原图入口。

## 点选与搜索

- 每个可见行政名称是原生按钮，支持鼠标和键盘，选中时有按下语义、描边和底色。
- 地图表面只查询当前显示的行政层；全国唐朝视野中先选省道，未命中省道时才选已有诸部背景。隐藏的县面不会抢先命中。
- 选中区域以深色 3.5 像素边线和 0.3 不透明度底色高亮原始辖区几何，不生成包围盒或替代范围。
- 地图直接点选不自动改变视野。缩放自动切换到别的层级时，旧层选中状态同步清除，不保留不可见辖区详情。
- 行政区搜索可查当前资料的所有层级。选结果时切换到该层级的手动预设、设置选中并定位整个原始几何；定位造成的缩放不会把结果自动隐藏。用户可再选“随缩放自动”。
- 行政区搜索结果消失后，焦点返回搜索输入框；地图标签重绘时保留仍可见标签的键盘焦点。
- 山川名称、城池点和地理参考点维持各自点击处理。自然模式不启用行政层；混合模式河湖表面不抢占行政区点选。

## 父地图接口

`shared/map-detail-levels.ts` 导出 `MapViewLevel`、`resolveMapDetailLevel`、`mapDetailZoomThresholds`。

```ts
resolveMapDetailLevel(
  viewLevel: MapViewLevel,
  zoom: number,
  availableLevels?: readonly BoundaryLevel[],
  options?: { primaryCountryCoverage?: boolean },
)
// requestedLevel, activeLevel, visibleLevels, interactiveLevels,
// showCities, isFallback
```

`HistoricalBoundaryLayer` 新增可选 `viewLevel`、`onViewLevelChange`、`onOpenAtlas`。父地图持有预设状态，同步控制城池点；边界组件通过实际资料、覆盖说明与缩放计算行政区显示。原图打开由父组件调用现有浏览器内原图查看器。

## 验证

`server/map-detail-levels.test.ts` 覆盖自动阈值、低缩放县面不可命中、唐国家范围缺失的降级策略、手动固定层、仅城池无行政面、跨层搜索定位及缺层处理。与既有 `server/boundaries.test.ts`、`server/map-interactions.test.ts` 合并运行，共 11 项通过；保留原边界来源、几何闭合和山川 / 行政互斥检查。最终父地图城池显示、原图按钮及浏览器视觉验收由主线程接入完成。
