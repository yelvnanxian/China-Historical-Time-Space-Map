# V0.3 验收记录

日期：2026-09-24。针对地图面积、时间探索、自然地理覆盖、边界精度、古今对照五项反馈，交付第一阶段体验改进。

## 本次完成

- 桌面地图接近全宽，档案默认收起为按需打开的浮动面板；压缩首屏介绍和页头，时间主操作靠近地图。手机保留较大地图及独立档案开关。
- 新增“沿时间 · 观山河”控制区：上一/下一节点、文字播放/暂停、当前事件与原始日期、进度、离散时间滑块，以及可展开的完整节点轨道。通史和专题入口常驻。改变的是已有事件/代表截面，没有生成缺失年份的数据。
- 用户已选择双名同屏：古今对照同时显示古名和现代对应地区，点击可查看代表截面称谓表。现有 `modern=1` 链接保持可用并启用双名。
- 新增可点击的现代自然地理标签和湖泊图层，河流更新为较详细的数据；分别控制河流、湖泊、山脉/山峰名称、海域名称。
- 25 项测试通过，含手写专题列表链接不误开首事件的新回归；TypeScript 与正式构建通过。

## 实际浏览器检查

- 桌面 1280×720：地图画布约 1227×435；页面位于顶部时，时间操作按钮底部约 690px，滑块底部约 713px，均在首屏内。
- 手机 390×844：地图画布约 462px 高，上一/播放/下一按钮底部约 756px；页面无横向溢出。地图放大并未使主时间操作不可发现。
- 450×650 短预览窗口另做适配，播放操作底部约 599px，仍在首屏中；验收后已恢复浏览器默认尺寸。
- 开启古今对照后，10 个专题地点生成古今双行名称；长安档案可展开代表截面称谓表，包含大兴城、奉元、西安等已收录称谓，并保留地区对应及改名时间尚未逐项核定的说明。
- 用滑块键盘操作选择末节点，URL、事件名称、原始日期与进度同步；末节点下一步禁用。倒数第二节点播放后自动停在最后节点；手动改变滑块会暂停播放。
- 通史切换与下一截面操作正常，仍支持政权范围切换；未将专题节点等同于逐年疆域。
- 点开太行山、渭河等自然标签可查看现代背景说明；原始数据链接固定到数据版本。关闭河流或湖泊图层后，对应自然标签同步移除，重新开启恢复。
- 手机先开自然信息卡再开历史档案时，自然信息卡自动关闭，不遮挡档案。档案可收起，地图及时间控制继续可用。
- 未捕获页面 JavaScript 错误。正式预览在 `http://127.0.0.1:3001`，地图、API 与自然地理资源同源提供。

## 数据检查

- 河流 277 个要素、湖泊 234 个要素，均为区域裁剪后的 Natural Earth 现代自然背景，不代表同数量的独立历史地理实体；部分湖泊是现代水库。
- 名称标签共 86 个：河流32、湖泊20、山脉/山峰26、海域8。河流常见中文译名明确标为项目显示翻译，保留原始名称和记录标识。
- 固定仓库提交、文件版本、下载时间、SHA-256、裁剪/简化方法、标签点派生方法均记录于 `public/data/natural-geography-sources.json`。86 个标签的位置已逐项回查来源几何；湖泊几何有效，输出哈希一致。
- 复现脚本及验证报告随数据保存。源数据中的一个明显错配中文名称已保留原名并记录原因。

## 分期保留

- 历史政权边界仍为概略示意；本次调整着色透明度以便阅读自然地理，没有提高历史边界的数据精度，也没有新增古城城墙或历史行政界。
- 国家/城市范围、更多城池及名称来源需要按地区样本继续建设。政权范围、行政区、建成区和古城范围应分别建模和验收。
- 山脉本次提供名称位置，没有声称提供精细山体模型；历史河道、湖岸、海岸以及森林/草地需有年代的独立资料。现代自然背景不随历史节点伪造变化。
- 工作量及后续数据依赖见 [V0.3 分阶段实施计划](V0.3分阶段实施计划.md)。
