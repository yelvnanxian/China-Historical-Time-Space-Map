# V0.2 验收记录

日期：2026-09-24。交付范围：安史之乱史料专题、本地正式构建预览及保留的通史探索。由前端/UI、后端、史料数据三个子代理并行实现，主代理负责集成、GIS 数据可行性核查与浏览器验收。

- 现有资料库共 11 个代表截面、28 个地点、34 个事件、19 个来源；安史之乱专题包含 10 个地点、12 个按史料顺序排列的节点。
- 保存《资治通鉴》卷217—222、《旧唐书》卷9、10的 8 份文本快照及来源修订信息。35 条已核对引文均逐字存在于各自对应的快照。

- URL 保存时期、专题、地点、事件、列表/地点视图、古今地名与路线开关。分享链接在本机预览可使用，跨设备访问需部署。

## 浏览器验收

通过 Codex 内置浏览器实际操作桌面及 390×844 手机尺寸：

- 首页默认进入范阳起兵节点，12 个事件节点和 10 个地点标记可见；点击洛阳、马嵬、灵武、河阳等节点后，URL、详情和地图同步。
- 点击地图马嵬驿可进入地点档案，明确显示近似位置和坐标未考证说明；后退可恢复马嵬事件。
- 事件列表刷新、列表→另一事件→后退→前进均恢复正确视图。发现的列表状态未写入 URL 问题已修复并纳入回归测试。
- 点击分享后，实际将复制的链接粘贴到页面搜索输入框，文本与当前正式版 URL 一致；随后清空搜索恢复正常界面。
- 从倒数第二个节点播放到“史朝义首级抵京”后自动暂停，下一节点按钮禁用，播放按钮变为从头播放。终点明确区分首级抵京地与未核定的死亡地点。
- 史料弹窗展示引文、具体支持的事实、数字文本差异、核查时间、卷级链接、版本和许可信息。
- 返回通史后搜索“大都”进入元代大都档案；搜索“肃宗在灵武即位”进入对应专题节点。
- 无效时期/专题/地点/事件参数可恢复为有效通史页面，无白屏。
- 手机页面宽度及 scrollWidth 均为 390，无页面横向溢出；内容顺序为地图、事件时间轴、详情。尺寸切换后当前时间轴节点重新进入可见范围。
- 正式构建以 `npm start` 启动于 `http://127.0.0.1:3001`，页面和 API 同端口，地图及工作线程正常；最终检查未捕获 JavaScript 错误。

## 保留的限制

- 政权轮廓仍为人工简化示意；专题始终标明使用 755 年参考截面，不表示 755—763 年逐年实际控制疆域。
- 地点均为现代对应地区的近似入口，没有升级为古城、关址、战场或驿站的考证坐标。自然地理底图仍为现代背景。
- 传统年份、月份、干支日未换算公历；数字年份是史书记年索引。原文核对不等于纸本校勘、史书一致或完整史实考证。
- GIS 候选核查见 `历史GIS数据来源可行性.md`；本版未导入 CHGIS/Hartwell/TGAZ 几何数据或地名库。
- 本版仍为只读 JSON 数据，没有管理后台、用户账户、PostGIS、3D 地图或公网部署。
