# V0.17 年份导航与边界对比验收

日期：2026-10-08。此版将浏览年份从朝代代表年中独立出来，联动有起讫年代的治所、确年事件与已有边界截面，并提供两个来源年份的分屏对比。年份可以切换，不等于已经具备逐年复原的疆域或全部城镇资料。

## 年份导航与城市纪年

- 朝代入口仍提供原有11个时期。旧链接不含 `year` 时沿用代表年；新链接保存 `year`，与时期、同城入口、事件及详情页状态一并解析和恢复。
- 年份必须是 `-9999` 至 `9999` 之间的非零整数。重复、超范围、非整数或非规范十进制参数被忽略。公元前使用负值存储、“前N年”显示，时间轴从前1年到1年不经过零年。
- 打开目录事件时，以事件自己的发生年为准，不被朝代代表年或冲突的URL年份覆盖。地图事件按确年或显式持续区间筛选，不能把全朝事件都视作所选年份的事件。
- 城市时间线现有 **571条节点**，本轮将既有节点接入年份导航；这不是本轮新增571条史实。点击节点保留同一目录地点并切换到记录年份。即使此城缺少目标时期专门档案，也不会自动跳回旧朝代或替换成另一座城。
- “本期／历代”仍可切换，当前年份的节点高亮。用户选择“历代”后跨朝代点击节点，保留该阅读范围，不重新收回“本期”。
- 宋元、明清等重叠年份先识别 `song-timeline-`、`ming-timeline-` 等记录所属时期，随后考虑事件的明确时期和当前时期，不仅凭一个年份把所有同期记录统一归到同一政权。
- 前221年以前、五代等时期空档和1912年以后的记录仍可阅读。界面显示“未收录时期”，不渲染相邻朝代的边界或治所来填空，也不将这些记录改写到最接近的朝代。

朝内滑杆按真实年份跨度排列。资料停靠年汇总目录事件、所有城市纪年、边界目录、755／1200固定治所参考年和朝代默认年；同年合并并保留资料类别。滑杆吸附最近停靠年，等距时使用较早年份。前后按钮与键盘方向键逐资料年切换，下拉框可精确选择1080、1200等年，避免密集刻度难以命中。

拖动期间仅更新局部年份预览，松开、失去指针捕获或离开控件时消费同一待提交值；同一次拖动只提交一次导航。按钮、键盘和下拉选择即时提交。导航使用URL历史状态；刷新、分享和浏览器前后退恢复年份，不在拖动的每个中间值中堆叠历史记录。

宋代名城菜单与详情明确区分“1200年档案整理参考”和当前所选年份。旧 `politicalContext` 中“1200年为当前阅读截面”仅在显示层改为“档案参考年份”，原始JSON及史料引用保持原值。档案沿革、地区名称和政区说明并未因此成为逐年动态考定。

## 治所时序数据与数量口径

数据复用已归档的CHGIS V6官方时序源包：县级10,522行、府州级5,226行，共 **15,748行**。按原始起讫年闭区间筛选显示、搜索和点选；保留SHP点几何、DBF原文、源层级、原始行身份与定年规则，不从行政面中心生成城镇。

| 口径 | 数量 | 含义 |
| --- | ---: | --- |
| 原始源行 | 15,748 | 县级与府州级时序源文件总行数 |
| 通过基础校验 | 14,862 | `manifest.uniqueFeatureCount`使用这一口径 |
| 隔离源行 | 886 | 坐标、定年或名称等异常，不进入发布包 |
| 11个时期包内不同源行 | 14,778 | 按时期交集实际发布的不同源行，不是各包数量之和 |
| 有效但不与11个时期相交 | 84 | 保留审计记录，不塞入相邻朝代 |

同一源行的长存续区间可能进入多个朝代包。上述数字均是来源记录口径，不能相加成“中国历代城镇总数”，也不是逐年核定的城市数量。CHGIS明确说明1350年以前仍有覆盖缺口；原始治所文件没有完整政权、上级隶属字段。

886条隔离原因可重叠：坐标属性与SHP相差超过0.02度829条、无效起讫区间28条、单年切片规则与区间冲突20条、无效坐标10条、未核定中文名称1条、异常历史年份2条。11911等异常源值没有被擅自改成1911。来源日期宽泛或规则缺失但未触发隔离的记录，仍标作“时序候选”并保留不确定性。

唐755年的候选点为 **1,681条**，比旧固定包的1,682条少一条：阆中郡 `SYS_ID=211282` 的单年切片规则与起讫区间冲突，现隔离。差额不是古城消失的历史判断，也没有通过挪点或补点抵消。当前1,023个有效755源点保留既有府州参考关联，仍须区分755年治所和741年近似模型。

宋1200年的候选点为 **1,560条**。既有20条审核关系仅在1200年且源记录有效时显示政权、参考辖区及目录档案入口；其他年份不继承这些固定年关联。755年的关联和县治诊断也只按既有适用年份使用。缺少关联时保留治所原始记录，不通过同名、最近位置或点在面内补配隶属。

府州级源点6级起显示、县级源点8级起显示；实际行政类型另列，军、监等不因源文件分组而统一改称府或县。名称数量会受视野和避让限制，完整记录并未从数据中删除。切期按需加载并中止旧请求；切年在当前包内筛选。1911年截止的记录不会被自动延长到1912年。

完整11期计数、数据生成、异常分类与复现方式见[按年份筛选历史治所](按年份筛选历史治所.md)。来源：[CHGIS V6县级时序点](https://doi.org/10.7910/DVN/Q9VOF5)、[CHGIS V6府州级时序点](https://doi.org/10.7910/DVN/WW1PD6)。

## 浏览年份与边界参考年

主地图选择同一时期内距离浏览年份最近的已有边界，等距时使用较早截面。它不跨朝代借用边界，不插值，也不把旧几何改名为新年份。例如：

| 浏览年 | 边界资料 | 解释 |
| --- | --- | --- |
| 唐755 | 唐741 | 参考近似行政模型，并非755年精确疆界 |
| 宋1080 | 宋辽1080 | 使用现有1080年来源轮廓 |
| 宋1138 | 宋辽1080 | 最近已有同朝截面，明确与浏览年不同 |
| 宋1200 | 宋金1200 | 使用现有1200年来源轮廓 |
| 清1911 | 清末1911 | 使用现有1911年来源轮廓 |
| 汉2、未收录时期1932 | 无可用边界截面 | 保留缺档状态，不替换为另一朝代模型 |

年份导航旁和地图边界说明分别显示所选年与参考年。治所随着原始存续区间变化，不意味着边界也具有同样的逐年粒度。Hartwell近似模型、CHGIS记录和城市史料关联仍各有来源限制，参考辖区也不等于城墙范围或完整国界。

## 分屏边界对比

“整个区域”允许从 **741、1080、1200、1290、1391、1820、1911** 七个已有来源截面中选择两个。左右共享拖动与缩放视野；选中另一侧正在使用的年份会交换两侧，避免重复。层级随缩放调整，边界仍使用来源原始多边形，不平滑、插值或推算缺失年代。

“同城辖区”限唐741、宋1200、明1391三组已有城市关联。按目录地点的明确关联ID读取准确图层；不根据同名、别名、现代对应、点面包含或最近行政面猜测。未关联的一侧显示具体缺口并留空，可用“适配两侧辖区”查看已取得的参考面。

对比可收起、展开或关闭；相机同步保存最后视野，收起重建不应触发相机循环反馈。几何按请求标识隔离，切换年份或关闭时中止过时请求；资料、网络或WebGL失败显示重试入口，不保留错期多边形充当新结果。这些实现和失败分支的存在，不等于已经完成所有设备与失败场景的浏览器测试。
