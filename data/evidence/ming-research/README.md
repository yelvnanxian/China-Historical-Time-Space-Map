# 明代地理志史料包

本目录保存明代建置与治所的第一批史料核查结果，供地图详情卡引用。本轮以清代编纂正史《明史》地理志为一条文献链，不称为明代同期原始档案；仍需以同期地方志、舆图和遗址资料互证。

`geography.json` 包含 32 条研究档案：28 个城市入口及凤阳府、淮安府、云南府、贵阳府 4 个未新增城市点的边界研究条目。总计 76 段逐字引文，来源为地理志卷 40—46 的 7 个固定修订快照。

## 重建与来源

依次运行：

```sh
python3 scripts/research-ming-geography.py
python3 scripts/build-ming-content.py
```

两个脚本均离线运行。前者只读取本目录固定快照，后者将 28 个档案合入 `public/data/city-period-profiles.json`，将 63 条有明确纪年的新节点及 2 条旧节点证据合并到 `public/data/historical-context.json`。重庆原文仅记“洪武中”，未编造确切年份；27 个城市有本轮新增的纪年节点。

每卷同时保存：

- `sources/mingshi-N.api.json`：含页号、修订号和原始 wikitext 的 API 响应，原样保留。
- `sources/mingshi-N.txt`：由原始 wikitext 仅展开 `YL` 年号模板和维基链接得到的文本，避免页面显示模板语法。
- `geography.json.sources`：两个快照的 SHA-256、固定修订号和回查链接。

每条 `facts[].evidence[]` 都带 `sourceId`、逐字 `quote`、`sourceTitle`、卷/府定位和 `sourceUrl`。构建时断言所有引文存在于对应文本快照中。

## 数据边界

本包记录史书明确写出的建置、隶属、改名、附郭县、王府与地理线索。`confidence: documented-administrative-description` 表示文字已在快照中找到，不表示现代坐标或精确边界已经核定。府、县、卫所、宣慰司和城内王府保持分层；`boundaryClaims` 为 0，不据文字绘制精确府界。

地理志的领州县总数为跨年代综合记载，不作为 1391 年或 1582 年的精确政区快照。1391 年 Hartwell 近似模型比 1582 年阅读截面早，跨年变更需要继续保留。正文采用简体，逐字引文保留原字形。

容易误读的项目已单独修正：

- 扬州的淮海—维扬—扬州、苏州、杭州等改府涉及明建国前纪年，不标为洪武年间。
- 太原县入口保留晋阳地区参考点；府治阳曲另行说明，不用同名府史料移动点位。
- 宁夏卫 1393 年始置、1395 年罢、1403 年复置；不能将 1582 年名称直接解释为 1391 年模型时相。
- 贵阳 1569 年改名、1601 年升军民府；1582 年仅称贵阳府，新贵县 1586 年才设。
- 开封条记河道与城池的相对位置改变，没有据此声称城址发生迁移。
