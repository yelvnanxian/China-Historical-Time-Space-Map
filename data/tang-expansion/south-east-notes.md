## 时间与命名

摘要概览 618—907 年，不限于地图代表年 755。新增地点 `nameByPeriod.tang` 采用 755 年的州郡、都护府正式名称，`name`、`aliases` 保留读者熟悉的州名、县名和现代地名。9 个既有地点继续使用现有城市标签，在 `namingNote` 说明当年郡县关系。

重点分辨：

- 丹阳郡治丹徒，对应镇江；不以现代丹阳市代替。
- 余姚郡治鄮县，821 年才迁州治至三江口；现代宁波点不能代表 755 年郡治。
- 鄂州江夏郡治所对应武昌，不是现代鄂州市。
- 梓潼郡治郪县，对应三台，不是现代梓潼县。
- 德阳郡治雒县，对应广汉，不是现代德阳市中心。
- 普安郡治普安；现代剑阁县坐标不代表唐普安城或剑门关。
- 唐绵州巴西郡与隋阆中地区巴西郡，属于不同年代、不同位置的沿革。
- 南诏太和城按同时期展示，不能解释为唐朝直辖。
- 安南府治宋平，唐后期经历南诏攻占和唐收复；大罗城营建另属后期节点。

## 来源与复核

建置以《旧唐书》卷 39、40、41 地理志为主要文本，保存了维基文库固定修订全文。经济文化内容补充百科固定修订快照。构建过程校验每个来源的 SHA-256，以及每段引文在快照中的完整子串匹配；这证明引文来自保存文本，不等同于对所有史实完成独立学术考证。

原始采集目录保留了未采用的备选页面与全文。正式采用的来源以 bundle 的 `sources` 列表为准；勿把目录下所有百科页面自动导入产品。

未照录到摘要的明显问题包括：现代百科成都市条把成都升府提前到 756 年（本次用《旧唐书》757 年）、汉中市条把兴元年份错写为 874 年（本次用古籍兴元元年 784）、南宁市条的“武德四年（612年）”、越州条的“乾元元年（768年）”。剑州改郡年份在资料中可能不一，摘要仅用“天宝时”，755 年的普安郡名有原文支持。宣州采用古籍明确的 765 年分置池州，避免现代百科对 787 年观察使、节度使职衔的混用。

现代参考坐标由中文与英文维基百科 `coordinates|revisions` API 批量获取，原始响应保留页面修订号和坐标。经纬度取四位小数仅供现代地区定位，不核定古城、城垣或精确治所。该 API 来源供 catalog 地点坐标引用，未作为唐史原文证据。

原文引文保留繁简字形。所有展示摘要、命名说明、关系说明、证据解释、地点名与别名均通过 OpenCC `t → cn` 审计。
